### Recommendations
1. **P2 — OAuth token delivery** (medium effort): Consider mounting the token via a short-lived pipe or file descriptor instead of env, or explicitly drop the env var from the subprocess after startup if the CLI supports it. The current allowlist (`_SAFE_ENV_KEYS`) is good; the residual risk is the env visibility mechanism.
2. **P2 — Plugin integrity** (low effort): Add a file-integrity check (hash or signature) for plugin `.py` files before `exec_module`, or restrict the plugins directory to read-only in production Quadlet units.
3. **P3 — Handler name validation** (low effort): Validate `cmd.handler` against a public-name pattern (e.g., no leading underscore) before `getattr` in `command_loader.py`.
4. **P3 — Error-message sanitization** (low effort): Redact or truncate `token` in the `config_command` error response before returning it to the user.
5. **P3 — Absolute binary path** (low effort): Use an absolute path to the `claude` binary in `AgentRefiner` (e.g., from a config knob or `shutil.which` cached at install time) instead of relying on `$PATH` at runtime.
6. **P3 — Broader env sanitization** (low effort): Expand `_identity_env` sanitization to strip all non-printable characters (`str.isprintable()`) before injecting into `GIT_COMMITTER_NAME` / `GIT_COMMITTER_EMAIL`.
