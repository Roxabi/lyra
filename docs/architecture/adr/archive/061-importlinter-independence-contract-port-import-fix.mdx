## Original Summary

Fixed core modules to import from `lyra.core.ports.*` directly instead of floating modules, reducing `ignore_imports` in the shared-modules-independence contract from 4 to 2, and introduced `STTProtocol` / `TTSProtocol` ports in `lyra.core.ports`.
