### Summary
Test infrastructure shows one long function (105 lines) and several DRY violations across the factory/fake layers, including duplicated mock builders, near-identical adapter factories, and a god module for bootstrap patching.

### Recommendations
1. **Split `patch_all` into focused helpers** (effort: medium) — Extract `patch_hub_capture`, `patch_adapters`, `patch_stores`, `patch_auth` from `patch_all`; move nested `CapturingHub`/`CapturingDcAdapter` to module level.
2. **Consolidate `_make_ctx_mock` to a single location** (effort: low) — Keep the one in `tests/factories/pools.py` and import it from `tests/fixtures/agent_harness.py`.
3. **Remove or merge `make_text_message` duplicates** (effort: low) — Deprecate `tests/factories/agents.py` version; point callers to `tests/helpers/messages.py` which supports `**overrides`.
4. **Dedupe `make_tg_adapter` / `telegram_adapter`** (effort: low) — Have the fixture call the plain function.
5. **Break up `tests/factories/bootstrap.py`** (effort: medium) — Split into `tests/factories/bootstrap/{adapters,stores,auth,nats}.py` or similar; the 402-line file is doing the work of 4 modules.
6. **Add cleanup for `_open_pairing_stores` / `_open_pairing_managers`** (effort: low) — Either use a pytest fixture with teardown, or clear the lists after use.
7. **Introduce a single `_make_inbound_msg` helper for adapter factories** (effort: low) — One function with `platform: str` and default maps; `make_tg_msg`/`make_dc_msg` become thin wrappers.
8. **Delete `tests/fakes/agents.py` `FakeSTT`** (effort: low) — Replace usages with `tests.fakes.drivers.FakeStt` which is protocol-compliant.
9. **Remove `tests/factories/__init__.py` wildcard imports** (effort: low) — Replace with explicit re-exports.
10. **Remove deprecated `tests/fixtures/fake_drivers.py` shim** (effort: low) — Update imports and delete.
