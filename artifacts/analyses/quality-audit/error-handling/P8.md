### Summary
P8 (LLM, agents, stages, misc) contains 3 P1 issues: two control-plane methods in `llm_client.py` silently drop transport `Err` results, and `attachment_ingest.py` suppresses original exception context with `from None`. No P0 critical issues (no bare `except:` or `BaseException` catches). Broad `except Exception:` patterns are numerous, mostly marked `DEBT:boundary-broad-catch` or `noqa: BLE001` and are intentional, but several lack retry logic on network/IO paths.

### Recommendations
1. **Fix swallowed transport errors in `llm_client.py`**: `reset()`, `switch_cwd()`, and `resume_and_reset()` should check `isinstance(result, Ok)` and log `Err` results before returning. Consider retry with `RetryDecorator` or `CircuitBreakerDecorator` if these are transient.
2. **Remove `from None` in `attachment_ingest.py:41`**: Preserve the original `ValueError` context by dropping `from None` so operators see the full traceback when `LYRA_MAX_ATTACHMENT_INGEST_BYTES` is malformed.
3. **Narrow broad catches in `attachment_ingest.py`**: Replace `except Exception:` with specific exception types (`BlobWriteError`, `httpx.HTTPError`, `OSError`, `asyncio.TimeoutError`) in audio and non-audio ingest paths.
4. **Add retry to monitoring HTTP checks**: `check_http_health`, `check_nats_varz`, and `check_audio_*` should use `httpx` with `httpx.AsyncClient` retries or wrap the calls in a retry loop for transient network failures.
5. **Audit `_handlers.py` and `auth.py`**: Add `log.warning()` inside the `except Exception: pass` blocks in `_emit_audit` and `_emit_unauthorized_audit` so audit failures are visible.
6. **Narrow `RuntimeError` in `session_builder.py`**: Replace `except (sqlite3.Error, RuntimeError):` with specific store exceptions (e.g., `StoreNotFoundError`, `ConnectionError`) if available, or catch the documented store error types.
