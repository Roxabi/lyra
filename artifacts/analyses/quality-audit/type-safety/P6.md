### Recommendations
1. **Remove broad pyright suppression** (`wiring_helpers.py:3`) — effort: XS. Replace with targeted `# type: ignore` on specific lines or fix the underlying attribute/argument issues. This is the highest-impact fix.
2. **Replace `Any` with proper NATS client type** across 7 files — effort: S. The `nats.aio.client.Client` type is available via `TYPE_CHECKING` in most files already; inline the import or use the existing pattern.
3. **Replace `Any` with concrete adapter/store types** in standalone wiring — effort: S. `standalone_telegram.py` and `standalone_discord.py` use `Any` for `bot_cfg`, `tg_turn_store`, `dc_thread_store`, `dc_turn_store`. These are known types (`TelegramBotConfig`, `TurnStore`, `ThreadStore`).
4. **Introduce `RawConfig = dict[str, object]` alias** in config loading — effort: XS. Replace `dict[str, Any]` in `config_loader.py`, `config_deprecation.py`, and `config/__init__.py` with a type alias. This removes the implicit `Any` hazard without requiring full `TypedDict` migration.
5. **Fix `_Stoppable` Protocol return type** — effort: XS. Change `async def stop(self) -> Any: ...` to `async def stop(self) -> None: ...` since all implementations return `None`.
6. **Fix `_on_nats_reconnect` return type** — effort: XS. Change `-> Any` to `-> Callable[[], Awaitable[None]]` or a named callback protocol.
7. **Address `BlobStorePort` `aclose` gap** — effort: S. The 3× `# type: ignore[union-attr]` on `blob_store.aclose()` indicate `BlobStorePort` (ADR-082) is missing `aclose()` in its protocol. Add the method to the port or use a narrower type at the call site.
