## Dissent

Recorded for traceability — these are panel disagreements that did NOT change the verdict:

- **B1, S1, S6 (devops dissent):** considered these latent/cosmetic ("no-op today", "type-ignore is cosmetic"). Majority overruled because T1↔T2 handoff surface is the load-bearing contract — every gap that compounds at flag-flip-time must close before T2.
- **B3 (architect dissent):** considered the race "test-driver scenarios only". Majority overruled — devops + product-lead both argue dispatch gate is part of the flag contract semantics, not a defensive race-guard.
- **B4, B5 (devops dissent):** considered these merge-blocking operator footguns. Majority overruled to `defer` because T1 has `LYRA_TYPING_ENABLED=false` default → no live ops risk today, and the PR description + post-merge runbook step mitigate footgun probability.
- **S4 (architect dissent):** considered this defensible defence-in-depth (`defer`). Majority overruled to `skip` — fixed-schema internal type with no exploitation surface.
- **S8 (architect dissent):** considered this `skip` (below 3-strike threshold per ADR-073). Majority overruled to `defer` — better to track than discard.
- **S9 (architect dissent):** considered this T2 polish. Majority overruled to `fix-now` because sibling to B2 (unanimous fix-now) — symmetric coverage is cheap to land now.
