### Summary
Partition T2 (Adapter, bootstrap, CLI tests) has 1 high-severity issue: `test_unified.py` replaces the entire `asyncio` module with a `MagicMock`, which is a dangerously broad mock. The remainder are medium-severity issues: real `asyncio.sleep` delays in typing tests, fragile `sleep(0)` yield loops in audit wiring, manual module-level constant mutations, one test without assertions, and an autouse event-loop fixture. Three low-severity findings catch `SystemExit` assertions without exit-code matching.

### Recommendations (prioritized, with effort estimate)

1. **Replace broad `asyncio` MagicMock with targeted `gather` patch** (P1, `tests/bootstrap/test_unified.py`, ~15 min)
   - Instead of `monkeypatch.setattr(unified_mod, "asyncio", MagicMock(gather=_orig_gather))`, patch only `unified_mod.asyncio.gather` with `AsyncMock` or `monkeypatch.setattr(unified_mod, "asyncio", unified_mod.asyncio)` + `monkeypatch.setattr(unified_mod.asyncio, "gather", _orig_gather)`.

2. **Replace real sleeps in typing tests with `asyncio.Event` gates** (P2, `tests/adapters/test_telegram_typing.py`, ~30 min)
   - Use an `asyncio.Event` that the mock callback sets, rather than sleeping for fixed wall-clock time. This removes 0.47 s of real sleep from the test suite.

3. **Replace `sleep(0)` yield loops with `asyncio.Event` or task-done checks** (P2, `tests/bootstrap/test_audit_bootstrap_wiring.py`, ~20 min)
   - Use an `asyncio.Event` that the `_capture` callback sets, or use `asyncio.wait_for` on the spawned task itself.

4. **Add `assert dv_module._deps_checked is True` to `test_skips_on_second_call`** (P2, `tests/adapters/test_discord_voice_session.py`, ~2 min)
   - Also add a guard assertion that the voice-deps function was not called (e.g., spy on `_check_voice_deps` or verify no exception). Even `assert dv_module._deps_checked is True` is better than none.

5. **Extract module-constant mutations into a shared fixture or use `monkeypatch`** (P2, `tests/adapters/test_nats_stream_decoder.py` + `tests/adapters/test_streaming_session.py`, ~20 min)
   - Use `monkeypatch.setattr(mod, "_LIVENESS_POLL_SECONDS", 0.05)` (pytest handles cleanup) instead of manual save/restore. Or create a fixture that monkeypatches both constants.

6. **Add `match` parameter to `pytest.raises(SystemExit)` assertions** (P3, `tests/bootstrap/test_adapter_standalone.py` + `tests/bootstrap/test_turn_writer_standalone_paths.py`, ~5 min)
   - Use `pytest.raises(SystemExit, match=r"1")` or `pytest.raises(SystemExit) as exc_info; assert exc_info.value.code == 1` to verify the exact exit code.

7. **Review `restore_event_loop` autouse fixture for cleanup** (P2, `tests/cli/test_voice_smoke.py`, ~10 min)
   - The fixture creates a new event loop per test but never closes it. If `asyncio.run()` already closed the old loop, the new one should be closed at fixture teardown to avoid resource leaks.
