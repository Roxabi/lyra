### Recommendations (prioritized, with effort estimate)

1. **Expose `WorkerPoolClient` transport via typed Protocol** — Eliminate the 3 `# type: ignore[attr-defined]` in `llm_client.py` by adding a `transport` property or `call` method to a `WorkerPoolClient` Protocol that `LlmClient` can depend on. Effort: medium (requires refactoring `lyra.transport.worker_pool_client` to expose a typed interface).

2. **Type `request.app.state` in blobstore** — Add a typed `AppState` dataclass/class to `blobstore/serve.py` so `request.app.state.store` and `request.app.state.audit_sink` have proper types. This removes the 2 `# type: ignore` in `_handlers.py` and `auth.py`. Effort: low.

3. **Fix `CliPoolCodec` model_cfg type** — The `# type: ignore[assignment]` in `cli_pool_codec.py:80` indicates `model_cfg` can be either a Pydantic model or a dict. Narrow the type to `ModelConfig | dict` and handle conversion explicitly. Effort: low.

4. **Replace `Any` in `OutboundFormatter` Protocol with platform-specific unions** — `trace_obj`, `ph`, and `buttons` are currently `Any` because they hold platform-native objects. Introduce a `PlatformPlaceholder` / `PlatformTrace` / `PlatformButton` union type (or per-platform `TypeVar` bound) so the Protocol is no longer fully opaque. Effort: medium (touches all per-platform formatter implementations).

5. **Add return annotation to `_make_lifespan`** — `blobstore/serve.py:104` should be `-> AsyncContextManager[None]`. Effort: trivial.

6. **Remove unused `Any` imports** — `src/lyra/tools/gh_token/helper.py` imports `Any` but only uses it in local variables. If `dict[str, Any]` is the intended local type, it is fine; no action needed unless stricter typing is desired.
