## Problem

Ruff BLE001 flags 121 blind `except Exception:` catches across 67 files. These catches silently swallow errors, making failures invisible and violating the project's logging discipline. The violations prevent enabling BLE001 in the default ruff select set, which blocks a quality gate that would catch future regressions.

The violations fall into four distinct categories requiring different fix strategies — they cannot be addressed with a single blanket approach.

## Who

- **Primary:** Lyra maintainers — the broad catches obscure runtime errors during debugging and incident response
- **Secondary:** CI/quality gates — BLE001 cannot be enabled globally until zero violations remain

## Constraints

- No blanket `# noqa` at file level — each suppressed catch must carry a one-line comment explaining intent
- Category C (error boundaries) must log with `exc_info=True` — no silent swallows permitted
- `uv run ruff check --select BLE001 .` must reach zero violations
- Existing tests must stay green
- BLE001 must NOT be added to `pyproject.toml` select set until violations are cleared
- `packages/roxabi-nats/` violations fixed in the same PR (monorepo package)

## Out of Scope

- Fixing other ruff violation categories
- Refactoring exception handling logic beyond narrowing types
- Adding new tests beyond keeping existing ones green

## Fix Strategy

| Category | Count | Pattern | Fix |
|----------|-------|---------|-----|
| A — JSON parse guards | ≈15–20 | `except Exception: payload = {}` or `return` | Narrow to `except (json.JSONDecodeError, ValueError)` |
| B — NATS/async teardown | ≈20–25 | `except Exception: log.debug(…)` or `pass` around transport ops | `except nats.errors.Error` where available; else `# noqa: BLE001  # nats teardown` |
| C — Error boundaries | ≈10–15 | Top-level `except Exception as exc` in middleware/bootstrap | Keep broad, enforce `log.exception(…)` + `# noqa: BLE001  # top-level boundary` |
| D — Tests | ≈5 | `except Exception: pass` in setup/teardown | Narrow to expected type or `# noqa: BLE001  # test teardown` |
