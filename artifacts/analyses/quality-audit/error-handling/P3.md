### Recommendations (prioritized, with effort estimate)

1. **Fix `BaseException` → `Exception` in `dispatch_streaming` guard** (effort: XS, 1 line)
   - File: `src/lyra/core/pool/pool_processor_exec.py` line 216
   - Change `except BaseException as exc:` to `except Exception as exc:` so `asyncio.CancelledError` propagates without being recorded as a circuit failure.

2. **Remove redundant circuit-failure recording in `process_one`** (effort: XS, 3 lines)
   - File: `src/lyra/core/pool/pool_processor_exec.py` lines 171-173
   - Remove the `except Exception as exc: record_circuit_failure(exc); raise` block around `await result`. The outer `guarded_process_one` already handles this. This eliminates double-counting.

3. **Add defensive error handling in memory freshness helpers** (effort: S, ~10 lines)
   - File: `src/lyra/core/memory/memory_freshness.py`
   - Wrap `json.loads` and `datetime.fromisoformat` in `try/except (json.JSONDecodeError, ValueError)` and return conservative defaults (`meta={}`, `is_stale=False`, `age_str=""`). This protects all upstream callers (`recall`, `upsert_concept`, `upsert_preference`) in one place.

4. **Add defensive JSON parsing in `memory.py` and `memory_upserts.py`** (effort: S, ~8 lines)
   - Files: `src/lyra/core/memory/memory.py` lines 169, 174; `src/lyra/core/memory/memory_upserts.py` lines 132, 200
   - Wrap each `json.loads` with `try/except json.JSONDecodeError` and fall back to `{}`. Alternatively, extract a shared `_safe_json_loads` helper in `memory_freshness.py` and reuse it across the memory layer.
