## Scope

Phase 3 — slice **S9** of the parent spec. Final cleanup once both adapters produce real
`BlobRef`s (blockers #1551 + #1552 merged). Retires the `PENDING_STORE_KEY` sentinel and the
STT `platform_ref` fallback. Converges voice fetch-failure degraded mode to `blob_ref=None`;
no path emits the retired sentinel.

This is a **cross-layer change (~15 files / 5 layers)**, not a 3-file cleanup. It includes a
type-contract change on `AudioPayload` and a breaking change to a versioned published package.

## Decisions

1. **Type contract** — `AudioPayload.blob_ref: BlobRef → BlobRef | None` (`None` = unresolved/degraded). Plan must audit every reader before deref: `middleware_stt.py:116` STT consumer, any `.audio.blob_ref.store_key` deref, NATS inbound serialization of `audio.blob_ref`.

2. **Voice degraded path** — adapters construct `blob_ref=None` initially (happy path overwrites it via `attachment_ingest` L165; degraded leaves `None`). `attachment_ingest` degraded branch (L157-159) sets `blob_ref=None` instead of preserving the sentinel. `middleware_stt`: on `blob_ref is None` → drop + user-facing error, no STT call.

3. **Consumption guard replacement (ADR-082)** — `blobstore_adapter.py:79`: replace `store_key == PENDING_STORE_KEY → raise` with `not store_key → raise` (empty store_key = contract violation; preserve the "a live `put()` must return a resolved ref" invariant; `store_key` is opaque).

4. **Breaking contracts bump** — removing the two public exports = breaking → `roxabi-contracts 0.5.0 → 0.6.0`. Cross-repo: verify voiceCLI#187 / imageCLI#101 (migrating to BlobStorePort) don't import the removed symbols; flag coordination. Audit `TtsResponse` model + `builders.py` for residual sentinel coupling.

## Success Criteria

- [ ] `grep -rn PENDING_STORE_KEY src/ packages/` = 0 (constant lives in `packages/`; both trees must be clean)
- [ ] STT integration passes on a real `BlobRef`; `platform_ref` fallback removed (no `isinstance(audio, bytes)` branch)
- [ ] Voice degraded mode emits `blob_ref=None`, never the retired sentinel
- [ ] `roxabi-contracts` version bumped to 0.6.0; no consumer imports the removed symbols
