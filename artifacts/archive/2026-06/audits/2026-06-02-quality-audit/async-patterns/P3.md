### Recommendations (prioritized, with effort estimate)

1. **Replace sync file I/O in JsonAgentStore with aiofiles or move to thread pool** (P2, effort: M)
   - `json_agent_store.py:71` (connect) and `:227` (_persist) are the only blocking I/O in the P3 partition.
   - Use `aiofiles` + `asyncio.to_thread(json.loads, ...)` or wrap `pathlib.Path.read_text/write_text` in `asyncio.to_thread()`.
   - JsonAgentStore is a test-only store, but the blocking I/O pattern is still risky if used in integration tests with real event loops.

2. **Remove redundant `create_task` in streaming post-hook** (P2, effort: XS)
   - `pool_processor_streaming.py:123`: Change `await asyncio.create_task(processor.post(...))` to `await processor.post(...)`.
   - The `try/except` block already handles exceptions; the `create_task` wrapper adds no value.

3. **Add task exception retrieval in Pool lifecycle** (P2, effort: S)
   - `pool.py:188` and `pool_processor.py:95`: Before overwriting `self._current_task` or setting it to `None`, call `self._current_task.exception()` if `self._current_task.done() and not self._current_task.cancelled()`.
   - Log the exception explicitly and consider dispatching a generic error reply to the user if the pool loop dies unexpectedly.

4. **Evaluate `LocalBus.put()` async signature vs. `put_nowait` implementation** (P3, effort: XS)
   - `inbound_bus.py:97`: Either change to `await self._queues[platform].put(item)` (blocking with backpressure) or rename to `put_nowait` and remove `async` to match the implementation.
   - The current mismatch is confusing and violates the principle of least surprise for Bus Protocol consumers.

5. **Audit `MessageManager.__init__` for async-safe loading** (P3, effort: XS)
   - `messages.py:44`: If called during async bootstrap, wrap the `open()`/`tomllib.load()` in `asyncio.to_thread()` or load the file at build/compile time.
   - File is small (<1 KB), so impact is low, but it's still a blocking syscall.
