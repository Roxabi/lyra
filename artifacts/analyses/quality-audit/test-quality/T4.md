### Recommendations
1. **Replace sleep polling with event-driven synchronization.** Use `asyncio.Event` or `asyncio.Queue` to signal readiness instead of `asyncio.sleep(0.5)` loops in `test_voice_routing.py` and `test_session_reply_to.py`.
2. **Add assertions to happy-path tests.** `test_audio_converter.py:22`, `test_vault_cli.py:28`, and `test_vault_cli.py:128` should assert the actual output (e.g., file exists, correct bytes, correct metadata) rather than just "no exception."
3. **Isolate trace writes to `tmp_path`.** Monkeypatch `_TRACES_DIR` at the class level or change `_write_trace` to accept a directory parameter so all pipeline tests write to per-test tmp paths.
4. **Make conditional assertions unconditional.** `test_session_dm_discord.py:157-161` and `test_session_telegram.py:186-190` should first assert that the bus was called, then assert the absence of `thread_session_id`.
5. **Implement or delete skipped tests.** Three tests (`test_reasoning_e2e.py:131`, `test_crash_recovery.py:295-316`, `test_crash_recovery.py:326-372`) are permanently skipped. Either implement them or remove them and track the coverage gap in an issue.
6. **Clarify `test_fallback_on_worker_stop`.** Rename it to `test_queue_group_with_single_worker` or implement the actual fallback logic (stop container + verify `NoRespondersError`).
7. **Strengthen streaming assertion.** `test_e2e_telegram_to_agent.py:199-201` should assert `outbound.to_text()` matches the expected concatenated stream content.
