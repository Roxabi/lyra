# P6 Code-Smell Audit — Bootstrap & Plugin Commands

## Summary

P6 contains the bootstrap orchestration layer (`src/lyra/bootstrap/`) and plugin commands (`src/lyra/commands/`). The bootstrap layer is the densest in the codebase, with 8 functions exceeding 80 lines, several DRY violations across Telegram/Discord platform pairs, and numerous private-attribute accesses across module boundaries. All 6 command plugins are clean with no significant structural issues.

## Recommendations

1. **Extract platform-generic wiring** — `wire_telegram_adapters` and `wire_discord_adapters` share 85% of their logic. Extract a `wire_platform_adapters(platform, bot_auths, ...)` with platform-specific callbacks for the 15% divergence (thread_store, watch_channels, token handling). Same for `wire_nats_telegram_proxies` / `wire_nats_discord_proxies`.
2. **Extract generic 3-layer NATS init** — `init_nats_tts`, `init_nats_stt`, `init_nats_image`, and `build_llm_client` all follow the same `NatsTransport -> WorkerPoolClient -> DomainClient` pattern. A single `_init_nats_domain_client(nc, subject, codec, name, ...)` factory would collapse 4 functions into 1.
3. **Extract `_wire_bot` factory** — The inner `_wire_bot` functions in `standalone_telegram.py` and `standalone_discord.py` are structurally identical: build inbound bus, create adapter, wire ingest, start adapter, start typing listener, start audio consumer. Extract a `wire_bot_standalone(nc, bot_cfg, platform, ...)` that accepts platform-specific adapter factory and typing resolver.
4. **Break up `_bootstrap_hub_standalone`** — Split into 4-5 phase functions: `_bootstrap_connect`, `_bootstrap_load_stores`, `_bootstrap_build_hub`, `_bootstrap_start_runtime`, `_bootstrap_run`. Each phase should be < 40 lines.
5. **Break up `run_lifecycle`** — Separate `start_runtime` (buses, dispatchers, health, adapters) from `wait_and_teardown` (watchdog, cancellation, cleanup).
6. **Add public accessors** — Replace all `_turn_store`, `_event_bus`, `_start_time`, `_last_processed_at`, `_bot_id`, `_typing`, `_outbound_listener`, `_resolve_channel`, `_resolve_identity_fn`, `_ingest_ctx`, `_nc`, `_store` accesses with public getters/setters or constructor parameters.
7. **Remove dead code** — Delete the empty `if TYPE_CHECKING: pass` block in `nats_wiring.py`.
