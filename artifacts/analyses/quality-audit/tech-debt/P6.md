### Recommendations
1. **Replace broad `except Exception` in bootstrap paths** (P1, effort: medium) — The 12 `DEBT:boundary-broad-catch` instances in startup/shutdown code should catch specific exceptions (`nats.errors.Error`, `OSError`, `ConnectionError`, etc.) instead of `Exception`. Start with `hub_standalone.py` and `adapter_standalone.py` as these are the most critical production paths.

2. **Remove deprecated TOML bot section support** (P1, effort: medium) — After confirming all production configs have migrated to BotStore (`lyra bot init`), delete `config_deprecation.py` and the `warn_deprecated_bot_sections` call chain in `config_loader.py`.

3. **Remove deprecated `STT_MODEL_SIZE` env var** (P2, effort: low) — Delete `_deprecated_env` and the fallback in `voice_overlay.py` after confirming consumers have migrated to `LYRA_STT_MODEL`.

4. **Extract named constants in `config_models.py`** (P2, effort: low) — Replace inline magic numbers with module-level constants (e.g., `DEFAULT_IDLE_TTL = 1200`, `DEFAULT_POOL_TTL_DAYS = 7`).

5. **Eliminate private-attribute access across boundaries** (P2, effort: medium) — Add public accessors or constructor parameters for `_typing`, `_outbound_listener`, `_worker_freshness`, `_event_bus`, `_authenticators`, `_store`, `_ctx`, `_alias_store`. This is the largest surface area of structural debt.

6. **Remove module-level pyright suppression** (P2, effort: low) — Replace `# pyright: reportAttributeAccessIssue=false, reportArgumentType=false` in `wiring_helpers.py` with targeted `type: ignore` on specific lines, then fix the underlying type issues.

7. **Clean up unused imports** (P3, effort: low) — Run `ruff check --select F401` and remove unused imports in `factory/config/__init__.py`, `factory/agent_factory.py`, `factory/hub/hub_core.py`, `commands/identity/handlers.py`, `commands/echo/handlers.py`.

8. **Wire audio consumers in unified mode** (P2, effort: medium) — Address follow-up #1521 in `unified.py` so unified mode has parity with standalone mode for audio delivery.
