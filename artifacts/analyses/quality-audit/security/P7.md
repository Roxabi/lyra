### Recommendations
1. **Scrub PII from logs**: Replace `tr.text` in `nats_stt_client.py` with a redacted placeholder (e.g., `len(tr.text)` or `is_whisper_noise=True`). Remove or redact `identity_key`, `admin_identity`, `secondary_id`, `primary_id`, `initiator_id` from all INFO/WARNING log lines in `auth_store.py`, `pairing.py`, and `identity_alias_store.py`.
2. **Scrub audit JSON fallback**: In `jetstream_sink.py`, truncate or redact the `json_str` before logging in degraded mode — emit only `event.kind`, `event.pool_id`, and `event.trace_id` instead of the full JSON.
3. **Fix SQL injection pattern**: Replace `f"PRAGMA user_version = {version}"` with parameterized execution or a safe helper in `bot_store_migrations.py`. Even though `version` is currently an int, treat all SQL composition as parameterized by default.
4. **Sanitization defense-in-depth**: Expand `_sanitize_key_part` in `message_index_kv.py` to use a whitelist or denylist approach that covers all NATS metacharacters (currently only `.`, `*`, `>` are replaced). Alternatively, rename the function to clarify it is KV-key scoped, not subject-safe.
5. **Eliminate str(e) at boundaries**: In `blobstore_adapter.py`, replace `str(e)` with a controlled message string (e.g., `"BlobNotFoundError"`) or use `type(e).__name__` to avoid propagating upstream error text.
