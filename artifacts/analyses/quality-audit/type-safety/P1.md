### Recommendations
1. **Replace `Any` in `_dispatch.py` with narrow union types** (effort: medium). `RoutedPayload` and dispatch helpers accept a closed set of shapes (`InboundMessage`, `OutboundMessage`, `AsyncIterator`, `OutboundAttachment`, etc.). Define a `typing.Union` alias (e.g., `OutboundPayload = OutboundMessage | AsyncIterator[RenderEvent] | OutboundAudio | AsyncIterator[OutboundAudioChunk] | OutboundAttachment`) and replace the 16 `Any` occurrences in `_dispatch.py` and `outbound_errors.py`. Estimated: 1–2 hours.
2. **Remove or refine `# type: ignore` in `middleware_stt.py`** (effort: low). The `hub._msg_manager` and `hub.dispatch_response` `union-attr` ignores indicate a structural typing gap. Either add a `MessageManager` type assertion before the call or introduce a `HasMessageManager` Protocol so the type checker can narrow `hub` safely. Estimated: 15–30 minutes.
3. **Type the `router` field in `PipelineContext` and `DispatchDeps`** (effort: low). `router` is currently `Any` but is always a `CommandRouter` (or `None`). Import the router type under `TYPE_CHECKING` and replace `Any` with `"CommandRouter | None"`. Estimated: 10 minutes.
4. **Replace `Any` in `ChannelAdapter` Protocol `raw`/`pending` parameters with `object`** (effort: low). `object` is the top type in Python and conveys “any value” without losing the safety signal that `Any` erases. Estimated: 5 minutes.
5. **Add type parameters to bare `set` and `list[dict]`** (effort: low). `_memory_tasks: set[asyncio.Task]` and `task_registry: set[asyncio.Task] | None`. `messages: list[dict[str, object]] | None` (or a narrow `MessageDict` TypedDict). Estimated: 10 minutes.
6. **Replace `Coroutine[Any, Any, None]` with `Coroutine[None, None, None]` in type aliases** (effort: low). The send/yield types are never used; `None` is more precise. Estimated: 5 minutes.
