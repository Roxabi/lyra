## Rationale

**B1+B2 are the same migration-completeness pattern**: v1/v2 dispatch paths were cut but behavioral side-effects (error signal, tool-seen flag) carried by the v1 path were not ported to v2 stubs. This is the highest-risk class of cutover debt and 3-0 consensus.

**B3 is a clear info-leak**: `str(exception)` on NATS/httpx exceptions embeds hostnames, auth tokens, connection strings. Fix is a one-liner discipline application matching the existing pattern at `stream_processor.py:352-356` (`type(exc).__name__` for NATS broadcast).

**B5+B6 form a silent-regression triad with B1**: error display broken AND undetectable in CI. The two test fixes must land with the code fixes.

**B4+W6+W7+S2 are doc/meta drift**: PR claims S4 done (it's deferred), CHANGELOG names wrong unit (clipool), runbook uses wrong restart procedure (timer-dependent), CLAUDE.md docs removed field. Low-effort, high-clarity for ops + future contributors.

**Effort estimate**: 12 items <5min each + 2 items <30min = ~90 min total batch.
