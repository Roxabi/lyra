# Harness Design Spec — #1490

> **Status:** design — pending implementation
> **Scope:** contracts, worker architecture, hub-side client, tool layer, container, bootstrap
> **Decisions:** Hub=pure-router, ContextBuilder=harness, MemoryInjection=harness, Cache=A3, Backend-routing=C2, Write-back=via turn-writer(lyra.turns.write); State-model=OPEN(stateless|stateful), HistoryRef/(b)=OPEN; Q4=A, Q5=B, Runtime=Custom

> **Amended 2026-05-28:** harness owns context-builder (not the store); state model reopened; backend routing = C2; write-back via turn-writer. See `artifacts/analyses/harness-epic-consolidated.md`.

---

## 1. Architecture Overview

**A1 update:** Hub = pure router (messages-plane only). Harness = context builder + turn-local memory.

**Memory injection = harness** (calls roxabi-cortex during context-build). This reverses the prior "hub pre-builds memory" assumption.

**Canonical store = shared layer** (turns.db today via turn-writer; backend per #640). Harness READS it. turn-writer remains sole writer (ADR-075). Harness does NOT own the store.

```
┌─────────────────────────────────────────────────────────────────────┐
│  HUB (pure router)                                                  │
│   ├─ receive inbound message (Telegram / Discord)                    │
│   ├─ fork on agent_config.backend:                                   │
│   │     claude-cli → clipool (C2 parallel path)                     │
│   │     harness    → lyra-harness (below)                           │
│   ├─ ship (pool_id, user_msg, agent_config) → lyra.harness.turn.request │
│   └─ forward harness reply → outbound adapter                        │
└─────────────────────────────────────────────────────────────────────┘
                          │
                          ▼
┌─────────────────────────────────────────────────────────────────────┐
│  lyra-harness                                                        │
│   ├─ read shared canonical store for conversation history            │
│   ├─ build messages[] (history + system prompt + tools)              │
│   │   memory injection = roxabi-cortex call during context-build     │
│   ├─ custom loop:                                                    │
│   │   while not done and turn_limit not hit:                        │
│   │     LLM call → LlmProvider (LiteLLMDriver / local — model-only) │
│   │     if ToolUseLlmEvent: execute via ToolRegistry                │
│   │       ├─ local tool → in-process                                 │
│   │       └─ Lyra tool → NATS proxy (lyra.jobs.*)                   │
│   │     emit HarnessTurnEvent stream → hub reply inbox              │
│   ├─ publish new turn(s) to lyra.turns.write                        │
│   │     (turn-writer persists; ADR-075 sole-writer preserved)        │
│   └─ return HarnessResponse (assistant_msg)                          │
└─────────────────────────────────────────────────────────────────────┘
```

> 🔓 **OPEN — State model (stateless vs stateful):** two variants under consideration; neither is decided.
>
> **Stateless:** harness re-reads the shared store each turn. No per-pool state. Queue-group scaling, any worker handles any pool_id. Requires a network read-path to the store (ties to #640 / context read-path decision (b)).
>
> **Stateful:** harness retains pool state between turns in process. Sticky routing (`pool_id` → worker). Warm local cache, no store read per turn. Requires consistent-hash or session-affinity in the NATS routing layer.
>
> **Critical note:** hub=pure-router, context-builder=harness, memory-injection=harness, and write-back via turn-writer all hold under **both** variants. Only the read pattern (re-read vs local cache) and routing (queue-group vs sticky) differ.

**Key change from original 3-concerns split:** Harness owns the context builder (not the canonical store). Hub is a thin router. Store is a shared read layer; turn-writer is the sole writer.

### 3.2 `HarnessWorker` — NATS adapter

```python
# harness_worker.py

_CMD_SUBJECT = "lyra.harness.turn.request"
_CONTROL_SUBJECT = "lyra.harness.control"
_HEARTBEAT_SUBJECT = "lyra.harness.heartbeat"
_QUEUE_GROUP = "harness-workers"
_ENVELOPE_NAME = "HarnessRequest"
_SCHEMA_VERSION = 1
_HEARTBEAT_INTERVAL = 30.0

class HarnessWorker(NatsAdapterBase):
    def __init__(
        self,
        loop: HarnessLoop,
        store: HarnessStore,
        *,
        timeout: float | None = None,
        identity_name: str | None = None,
    ) -> None:
        super().__init__(
            subject=_CMD_SUBJECT,
            queue_group=_QUEUE_GROUP,
            envelope_name=_ENVELOPE_NAME,
            schema_version=_SC_VERSION,
            timeout=timeout,
            heartbeat_subject=_HEARTBEAT_SUBJECT,
            heartbeat_interval=_HEARTBEAT_INTERVAL,
            identity_name=identity_name,
            wait_ready=False,
        )
        self._loop = loop
        self._store = store
        # only if STATE MODEL = stateful (OPEN); stateless variant holds no per-pool state
        self._pool_states: dict[str, PoolState] = {}

    def _extra_subjects(self) -> list[str]:
        return [_CONTROL_SUBJECT]

    async def handle(self, msg: Any, payload: dict) -> None:
        if msg.subject == _CONTROL_SUBJECT:
            await self._handle_control(msg, payload)
        else:
            await self._handle_turn(msg, payload)

    async def _handle_turn(self, msg: Any, payload: dict) -> None:
        try:
            req = HarnessRequest.model_validate(payload)
        except ValidationError:
            log.exception("harness_worker: HarnessRequest validation failed")
            await self.reply(msg, _make_error_chunk(..., code="worker.validation"))
            return

        # Read history from canonical store
        history = await self._store.read_history(req.pool_id)

        # Get or create pool state
        pool_state = self._pool_states.get(req.pool_id)
        if pool_state is None:
            pool_state = PoolState(pool_id=req.pool_id)
            self._pool_states[req.pool_id] = pool_state

        # Run the agentic loop
        turn_result = await self._loop.run_turn(req, history, pool_state)

        # Stream events back via reply inbox
        for event in turn_result.events:
            await self.reply(msg, _encode_turn_event(event))

        # Publish new turn(s) to persistence plane — turn-writer persists (ADR-075 sole-writer).
        # ADR-076 amendment pending: persistence-plane producer moves hub→harness.
        await self._turns_producer.publish("lyra.turns.write", req.pool_id, turn_result.new_messages)

        # Terminal HarnessResponse
        resp = turn_result.to_response(req)
        await self.reply(msg, _encode_response(resp))

    async def _handle_control(self, msg: Any, payload: dict) -> None:
        ...  # fork, resume, rewind, drain
```

### 3.3 `HarnessLoop` — custom thin loop

```python
# harness_loop.py

@dataclass
class TurnResult:
    """A9: Immutable result object returned by run_turn()."""
    events: list[HarnessTurnEvent]
    assistant_message: Message
    new_messages: list[Message]  # messages to append to canonical store
    tool_summaries: list[ToolUseSummary]
    turn_count: int
    duration_ms: float

    def to_response(self, req: HarnessRequest) -> HarnessResponse:
        return HarnessResponse(
            request_id=req.request_id,
            pool_id=req.pool_id,
            trace_id=req.trace_id,
            assistant_message=self.assistant_message,
            tool_calls_summary=self.tool_summaries,
            duration_ms=self.duration_ms,
            turn_count=self.turn_count,
        )

class HarnessLoop:
    """Custom agentic loop: one turn = one LLM conversation turn.

    A9: run_turn() returns a TurnResult object directly. No mutable side effects.
    """

    def __init__(
        self,
        llm_provider: LlmProvider,
        tool_registry: HybridToolRegistry,
        max_turns: int = 10,
    ) -> None:
        self._llm = llm_provider
        self._tools = tool_registry
        self._max_turns = max_turns

    async def run_turn(
        self, req: HarnessRequest, history: list[Message], pool_state: PoolState
    ) -> TurnResult:
        """Run the agentic loop and return a TurnResult.

        Outbound LlmProvider = MODEL-ONLY drivers (LiteLLMDriver / local).
        CliNatsDriver is NOT used here — claude-cli is reached via the hub→clipool
        parallel path (C2) and never wrapped by the harness loop.

        A4: pool_id is passed to the outbound LlmProvider for session tracking /
        prefix-cache affinity (A3: caching is the inference backend's job; harness
        passes pool_id through, clipool keeps --resume affinity via pool_sessions).
        """
        messages = list(history)
        messages.append(Message(role="user", content=req.user_message))

        turn_count = 0
        assistant_message = Message(role="assistant", content="")
        tool_summaries: list[ToolUseSummary] = []
        events: list[HarnessTurnEvent] = []
        start_time = time.monotonic()

        while turn_count < (req.model.max_turns or self._max_turns):
            turn_count += 1
            stream = self._llm.stream(
                pool_id=req.pool_id,
                text=messages[-1].content if messages else "",
                model_cfg=req.model,
                system_prompt=req.system_prompt,
                messages=[m.model_dump() for m in messages],
            )

            async for event in stream:
                if isinstance(event, TextLlmEvent):
                    assistant_message.content += event.text
                    events.append(HarnessTurnEvent(
                        request_id=req.request_id,
                        trace_id=req.trace_id,
                        event_type="text",
                        delta=event.text,
                    ))
                elif isinstance(event, ToolUseLlmEvent):
                    events.append(HarnessTurnEvent(
                        request_id=req.request_id,
                        trace_id=req.trace_id,
                        event_type="tool_use",
                        tool_name=event.tool_name,
                        tool_id=event.tool_id,
                        tool_input=event.input,
                    ))
                    # Execute tool
                    result = await self._tools.execute(
                        name=event.tool_name,
                        input=event.input,
                        pool_id=req.pool_id,
                        trace_id=req.trace_id,
                    )
                    tool_summaries.append(result.summary)
                    events.append(HarnessTurnEvent(
                        request_id=req.request_id,
                        trace_id=req.trace_id,
                        event_type="tool_result",
                        tool_id=event.tool_id,
                        tool_result=result.data,
                    ))
                    # A5: Serialize structured dict to JSON string for Message.content
                    content = result.data if isinstance(result.data, str) else json.dumps(result.data)
                    messages.append(Message(
                        role="tool",
                        content=content,
                        tool_call_id=event.tool_id,
                        name=event.tool_name,
                    ))
                elif isinstance(event, ResultLlmEvent):
                    if event.is_error:
                        events.append(HarnessTurnEvent(
                            request_id=req.request_id,
                            trace_id=req.trace_id,
                            event_type="error",
                            is_error=True,
                            error=ErrorInfo(...),
                        ))
                        return TurnResult(
                            events=events,
                            assistant_message=assistant_message,
                            new_messages=messages,
                            tool_summaries=tool_summaries,
                            turn_count=turn_count,
                            duration_ms=...,  # compute
                        )
                    break  # turn done

            # If no tool was called, turn is complete
            if not any(isinstance(e, ToolUseLlmEvent) for e in ...):
                break

        return TurnResult(
            events=events,
            assistant_message=assistant_message,
            new_messages=messages,
            tool_summaries=tool_summaries,
            turn_count=turn_count,
            duration_ms=...,  # compute
        )
```

# tool_registry.py

class HybridToolRegistry:
    """Q1=C: shared tools via NATS proxy + local tools in-process.

    A6: LyraToolProxy is a full job producer client. It submits jobs to
    lyra.jobs.* and waits for JobResult. The harness includes a JobProducer
    client (codec + retry + timeout) from the worker fleet (#1044).
    """

    def __init__(
        self,
        local: LocalToolRegistry,
        lyra_proxy: LyraToolProxy,
    ) -> None:
        self._local = local
        self._lyra = lyra_proxy

    async def execute(
        self, name: str, input: dict, pool_id: str, trace_id: str
    ) -> ToolResult:
        descriptor = self._resolve(name)
        if descriptor.registry == "local":
            return await self._local.execute(name, input, pool_id, trace_id)
        return await self._lyra.execute(name, input, pool_id, trace_id)

## 4. Hub-Side Client (`src/lyra/llm/harness_client.py`)

New `LlmProvider` implementation that ships turns to the harness.

```python
# harness_client.py

class HarnessLlmProvider:
    """Hub-side LlmProvider that targets lyra-harness over NATS.

    P1: No degradation logic here. Hub handles harness unavailability
    (timeout, no workers) at a higher level (retry, fallback, or error to user).
    """

    capabilities = {"streaming": True, "auth": "nats", "tools": True}

    def __init__(
        self,
        pool: WorkerPoolClient,
        codec: HarnessCodec,
        *,
        timeout: float | None = None,
    ) -> None:
        self._pool = pool
        self._codec = codec
        self._timeout = timeout

    async def stream(
        self, pool_id, text, model_cfg, system_prompt, *, messages=None
    ) -> AsyncIterator[LlmEvent]:
        # Encode HarnessRequest
        payload, trace_id = self._codec.encode(
            pool_id=pool_id,
            text=text,
            model_cfg=model_cfg,
            system_prompt=system_prompt,
            messages=messages,
            stream=True,
        )
        # Stream request to harness
        async for result in self._pool.stream_request(
            "lyra.harness.turn.request", payload, timeout=self._timeout
        ):
            event = self._codec.decode_chunk(result)
            if event is None:
                continue
            yield event
            if isinstance(event, ResultLlmEvent):
                return

    async def complete(...) -> LlmResult:
        # Non-streaming: collect all events, return final
        ...

    def is_alive(self, pool_id: str) -> bool:
        return self._pool.is_pool_alive()

    async def stop(self) -> None:
        await self._pool.stop()
```

async def _bootstrap_harness_standalone(raw_config: dict) -> None:
    run_git_ownership_probe()

        await store.close()

## 8. Wiring & Backend Enum (Q4=A, Backend-routing=C2)

```python
_VALID_BACKENDS: frozenset[str] = frozenset({"claude-cli", "harness"})
```

**C2 routing rule (hub forks on `agent_config.backend`):**

| `agent_config.backend` | Hub routes to | Notes |
|---|---|---|
| `claude-cli` | clipool | claude-cli is harness+model (runs its own loop); reached via clipool path |
| `harness` | lyra-harness | lyra-harness is the agentic loop for MODEL-ONLY backends (LiteLLMDriver / local / #61 SLMs) |

`CliNatsDriver` is **not** used by the harness loop. It belongs to the hub→clipool path only.

## 9. pool_id Lifecycle (Extra)

The harness supports conversation operations via `lyra.harness.control`:

| Command | Action |
|---|---|
| `fork` | Create new pool_id from current history snapshot |
| `resume` | Restore pool_id from canonical store (after worker restart) |
| `rewind` | Truncate history to N turns back |
| `reset` | Clear pool_id state (new conversation) |
| `drain` | Stop accepting new turns, finish current |

These are **harness-side** operations (harness owns context). Hub sends control commands; harness executes.
