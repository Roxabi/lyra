## Phase 3: Archive Merged ADRs

For each merged ADR (037, 040, 044, 047, 050, 053, 054, 056, 060, 061, 062):

```bash

mv docs/architecture/adr/0XX-*.mdx docs/architecture/adr/archive/

# Replace content with superseded notice
```

Archive template:
```mdx
---
title: "ADR-0XX: [Original Title]"
description: "[Original description]"

## Status

This ADR has been merged into [ADR-YYY](../YYY-*.mdx). The decision remains valid; content has been consolidated for readability.

## Summary

[1-2 sentence summary of the original decision]
```
