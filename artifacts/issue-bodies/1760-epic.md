## Boundary · Control-plane ≠ Lyra Sentinelle

| | Control-plane (#1760) | Lyra Sentinelle (ADR-091) |
|---|---|---|
| Surface | Web console (chat, jobs, obs panels) | Discord #sentinelle |
| Consumer | Opérateur humain dans le browser | Module hub — alertes proactives |
| Events | Live workers/jobs (#1772) via #1767 | `factory.event.*` host + ingress + mail |
| Relation | **Parallèle** — pas de remplacement mutuel | Sentinelle peut pointer vers le dashboard en V2 |

**Operator web console** — the single human surface for running the factory (ADR-092). Lives in **`factory-dashboard`** container (renamed from `factory-web`, ADR-094).

## Architecture (ADR-094 — 2026-06-27)

**Evolve, do not fork.** One container, two internal axes:

| Axis | Module | Transport |
|---|---|---|
| **Chat opérateur** | Extend `src/factory/adapters/web/` (`WebAdapter`) | `factory.inbound/outbound.web.*` (phase 1) |
| **Control-plane BFF** | `src/factory/dashboard/` (new) — obs/jobs panels | Proxy Loki/Prom/Langfuse; `factory.event.*`; KV reads — **not** hub Pool |

Rejected: parallel `platform=dashboard` adapter (#1770) + second Quadlet unit.
