### Summary
P7 (Infra, NATS, transport, observability) is structurally sound: all 11 import-linter contracts pass, no cycles detected, and layers are respected. Findings are concentrated in three themes: (1) transport-agnostic `WorkerPoolClient` is concretely coupled to `NatsCircuitBreaker`, (2) `NatsChannelProxy` has near-limit file size and a cluster of small duplication/dead-code items, (3) `TurnWriter` has a one-off raw-SQL bypass for idempotent resume-counting.

### Recommendations (prioritized, with effort estimate)

1. **Inject circuit breaker into `WorkerPoolClient`** (P2, effort: small)
   Replace `from roxabi_nats.circuit_breaker import NatsCircuitBreaker` with a generic `_CircuitBreakerLike` protocol (or accept `NatsCircuitBreaker` via constructor DI). This is the only P2 and is a prerequisite for the future HTTP transport path.

2. **Extract shared `NatsChannelProxy` envelope helper** (P3, effort: tiny)
   Add a private `_publish_envelope(subject, type, stream_id, **fields)` method to remove the ~6-line duplication in `send`, `render_attachment`, and `render_audio`.

3. **Remove dead code `_safe_subject_token` + `_NATS_UNSAFE`** (P3, effort: tiny)
   Delete the unused helper and regex. `WorkScope` already validates tokens via `^[A-Za-z0-9_-]{1,48}$`.

4. **Consolidate codec decode boilerplate** (P3, effort: small)
   Introduce a `_decode_response` helper in `lyra.transport` or a base codec class that handles the common `Err` → `ValidationError` → `resp.ok` pipeline. Domain codecs would only supply the `Response` model class and the success/error result constructors.

5. **Extract shared JetStream provisioning helper** (P3, effort: small)
   Move the `add→BadRequestError→update` / `consumer_info→NotFoundError→add_consumer` pattern into a single `lyra.infrastructure.nats_provision.py` helper so `turn_writer/stream_setup.py` and `outbound_audio/stream_setup.py` call it instead of duplicating the logic.

6. **Move `TurnWriter` raw SQL into `TurnStore`** (P3, effort: small)
   Add an `idempotent_increment_resume_count(session_id, target_count, event_id)` method to `TurnStore` that encapsulates the `BEGIN/COMMIT/ROLLBACK` transaction. This keeps the writer as a pure dispatcher.

7. **Split `identity_alias_store.py`** (P3, effort: small)
   The file is at 299 lines. Extract the challenge-code logic (`create_challenge`, `validate_challenge`) into a separate `infrastructure/stores/link_challenge_store.py` module to create headroom.

8. **Split `NatsChannelProxy` audio / attachment methods** (P3, effort: small)
   Extract `render_audio`, `render_attachment`, and the unimplemented stream placeholders into a `nats_channel_proxy_audio.py` / `nats_channel_proxy_attachment.py` pair, or a single `nats_channel_proxy_media.py` module. This buys headroom under the 300-line cap and separates the text-path (send/send_streaming) from the media path.

9. **Complete `HttpTransport` skeleton** (P3, effort: medium)
   When P4 (#1281) is scheduled, wire real HTTP request/response logic. The current skeleton is a placeholder only.

10. **Inject `LYRA_TYPING_ENABLED` at bootstrap** (P3, effort: tiny)
    Read the env var in `bootstrap` and pass `enabled: bool` to `TypingPublisher` instead of letting the transport layer probe the environment.
