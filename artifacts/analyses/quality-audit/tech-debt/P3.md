### Recommendations
1. **Remove deprecated Pool constructor params** (P1, effort: M). Migrate all callers to `PoolConfig` and remove the individual param overrides. This resolves the PLR0913 noqa and the deprecated API surface. Tracked: existing comment at line 38.
2. **Extract queue constants to BusConfig** (P1, effort: S). Move `maxsize=100`, `queue_depth_threshold=100`, `staging_maxsize=500` to a `BusConfig` Pydantic model loaded from config.toml. Eliminates 4 magic numbers.
3. **Extract memory limits to MemoryConfig** (P1, effort: S). Move `token_budget=1000`, `limit=8`, `limit=10`, and preference sub-budget `300` into a `MemoryConfig` dataclass. Also replace `len(line) // 4` with a tokenizer-aware estimate or at least a named constant `CHARS_PER_TOKEN_ESTIMATE = 4`.
4. **Expose PairingConfig constants to config.toml** (P2, effort: S). Load `PairingConfig` from `[pairing]` config section so `ttl_seconds`, `rate_limit_window`, `max_pending` can be tuned without code changes.
5. **Extract turn_store limits to named constants** (P1, effort: XS). Define `DEFAULT_TURN_LIMIT = 50` and `DEFAULT_SESSION_LIMIT = 5` in `turn_store_protocol.py`.
6. **Narrow streaming protocol types** (P3, effort: M). Replace `object | None` parameters in `pool_processor_streaming.py` with a `Protocol` (e.g., `HasAclose`, `HasSessionId`, `StreamDoneEvent`). Removes 4 `type: ignore` suppressions.
7. **Audit broad-exception catches** (P3, effort: M). Replace `except Exception: # noqa: BLE001` with specific exception types where possible (e.g., `QueueFull`, `CancelledError`, `OSError`). The current pattern is defensive but hides real bugs.
