### Summary
Partition P2 (Agent model, CLI, commands) has 1 high-severity issue (protocol violation) and 7 medium-severity issues (coupling, NxM duplication, god modules). The `AgentRefiner` is typed with a concrete `AgentStore` instead of the `AgentSeederTarget` protocol defined in the same package. `AgentBase` is a god module mixing command routing, voice handling, memory, and hot-reload. `send()` and `send_streaming()` in CliPool duplicate ~80 lines of spawn/respawn/stale-resume logic.

### Recommendations
1. **Refine AgentRefiner to use AgentSeederTarget** (effort: 1h) — Change `store: AgentStore` to `store: AgentSeederTarget` in `agent_refiner.py`. No runtime change needed; removes the last concrete infrastructure dependency in `core/agent/`.

2. **Extract command routing from AgentBase** (effort: 4h) — Split `AgentBase` into `AgentBase` (pure processing) + `CommandAwareAgent` (wires `CommandRouter`). Move `_rebuild_command_router`, `_command_mgr`, `_command_loader` into a mixin or subclass. Addresses god-module + command coupling.

3. **Introduce PoolCommandContext protocol** (effort: 2h) — Define a narrow protocol with `turn_store`, `is_idle`, `resume_session`, `switch_workspace`, `submit`, `history` that `Pool` implements. `CommandRouter` and command handlers type against this protocol instead of `Pool`. Decouples commands from pool internals.

4. **Extract shared send preamble into _ensure_entry** (effort: 2h) — Factor the common spawn/respawn/mismatch logic from `send()` and `send_streaming()` into a single `async def _ensure_entry(...)` method that returns a live `_ProcessEntry`. The two public methods then call the protocol-specific I/O (`send_and_read` vs `send_and_read_stream`).

5. **Move CommandConfig to command_config.py** (effort: 30m) — Change `agent_config.py` and `agent_builder.py` to import `CommandConfig` from `command_config.py` instead of `command_router.py`. Breaks the transitive data-model -> router dependency.

6. **Consolidate processor dynamic import** (effort: 30m) — Extract the `try/importlib.import_module` pattern into a shared helper in `commands/` so `command_router.py` and `builtin_commands.py` share one implementation.
