### Summary
P1 (Hub, lifecycle, ports) has one high-severity port-purity violation in `ports/llm.py`, several medium-severity coupling issues where `PoolManager` and `HubRegistrationMixin` reach into private attributes of `Hub` and `Pool`, and a few low-severity typing/import hygiene issues. No critical (P0) issues or runtime layer violations were found.

### Recommendations
1. **P1 — Co-locate LLM port value objects** (effort: medium): Move `ModelConfig` and `LlmEvent` (or minimal type stubs) into `core/ports/llm.py` or a dedicated `core/ports/llm_types.py` so the driven port is self-contained. Alternatively, use `TYPE_CHECKING` for these imports and replace runtime signatures with string annotations. This removes the cross-core dependency.
2. **P2 — Narrow `PoolManager` deps** (effort: medium): Introduce a `PoolManagerDeps` dataclass or `PoolManagerContext` protocol that exposes only the `Hub` attributes `PoolManager` needs (max_pools, pool_ttl, turn_store, turn_publisher, message_index, pairing_manager, agent_registry, memory_tasks, cli_pool). This breaks the private-attribute coupling.
3. **P2 — Add public `Pool` registration API** (effort: low): Add public methods like `Pool.register_turn_store()`, `Pool.register_turn_publisher()`, `Pool.register_message_index()`, and a `Pool.is_configured` property. Replace `HubRegistrationMixin` private accesses with these calls.
4. **P2 — Fix `RateLimitMiddleware` deferred import** (effort: trivial): Replace the runtime `from ..hub import RoutingKey` with a top-level `from ..hub.hub_protocol import RoutingKey`.
5. **P2 — Type `tts` as `TtsProtocol`** (effort: trivial): Change `object` to `TtsProtocol` in `OutboundRouterDeps`, `OutboundRouter`, and `TtsDispatch`. Import `TtsProtocol` under `TYPE_CHECKING` if needed.
6. **P2 — Harden `register_agent` contract** (effort: medium): Define a `HubAwareAgent` protocol (or expand `AgentBase`) with explicit `memory`, `task_registry`, `on_debounce_change` hooks, instead of `hasattr`/`setattr` duck typing.
7. **P3 — Fix TYPE_CHECKING circular paths in outbound** (effort: trivial): Change `from lyra.core.hub import ChannelAdapter` to `from lyra.core.hub.hub_protocol import ChannelAdapter` in `outbound_dispatcher.py` and `_dispatch.py`.
