## Data Model & Consumers

```mermaid
classDiagram
  class ADR {
    +status: accepted|amended
    +banner: Current truth → page
    +body: Context/Decision (historique, gelé)
    +amendments: append-only (### Amendment YYYY-MM-DD | étiquette inline datée)
    +links: artifacts/, docs/ (mutable)
  }
  class DomainPage {
    +invariants courants (mutable, ≤350 l.)
    +table ADR archive: row(n°, statut, résumé) (mutable)
  }

    +units Quadlet, secrets, env vars, subjects (SSoT comportement)
  }
  ADR --> DomainPage : banner délègue le présent
  DomainPage --> ADR : row indexe statut+résumé
  ADR ..> Code : claims opératoires DOIVENT matcher
  DomainPage ..> Code : invariants DOIVENT matcher
```
