### Summary
Bootstrap layer has widespread private-attribute access violations (17 sites) and hosts business logic (SessionTools construction) that contradicts its "orchestration only" invariant. Commands layer is mostly clean, but `identity/handlers.py` reaches deep into Hub internals. NxM duplication between Telegram and Discord wiring is present across 4 file pairs. The importlinter layer contract is currently passing (11/11), but runtime coupling via private attributes is unchecked.
