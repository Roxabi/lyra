### Recommendations
1. **Remove monitoring package** (effort: M) — `lyra.monitoring` is deprecated (#1035). Plan removal in a dedicated issue. All `str(exc)` boundary violations in this package become moot once removed.
2. **Fix `str(exc)` boundary violations in monitoring** (effort: S) — If removal is delayed, replace `str(exc)` with `type(exc).__name__` in all CheckResult detail fields to align with SanitizedError boundary rules.
3. **Resolve inbound adapter-layer imports** (effort: M) — Move `TelegramAdapter`/`DiscordAdapter` dependencies out of `inbound/` stage modules. Wire parsers should receive a normalized interface, not an adapter reference. Tracked by #1283 Phase 6.
4. **Add outbound `str(exc)` pre-commit hook** (effort: S) — Implement `tools/check_outbound_str_exc.sh` as scoped in #1279. Validates no `str(exc)` or `f"...{exc}"` patterns exist on bus-bound paths.
5. **Config-drive monitoring thresholds** (effort: S) — Replace hardcoded model name, service names, NATS URL, and blobstore path in `MonitoringConfig` with env vars or TOML overrides.
6. **Eliminate `DEBT:wiring-bootstrap-deps` markers** (effort: L) — The 9 PLR0913 markers across `llm/decorators.py`, `agents/simple_agent.py`, `integrations/`, and `tools/gh_token/dispenser.py` indicate excessive constructor/method arity. Introduce config objects or builder pattern to reduce parameter count.
7. **Eliminate `DEBT:boundary-broad-catch` markers** (effort: M) — Replace broad `except Exception` in `TokenCache.read`, `mint` response parse, `Dispenser._handle`, and `SimpleAgent._register_session_commands` with typed exception lists where feasible.
8. **Config-drive magic thresholds** (effort: S) — Move hardcoded cache sizes (500), edit intervals (1.0s), truncation limits (120/117/48/512/8000), and timeouts (10s/30s) into `config.toml` or env vars with sensible defaults.
9. **Complete TODO(T4)** (effort: S) — Wire `MintError` to `MintFailureEvent` NATS publisher in `gh_token/helper.py` using `roxabi-contracts` gh/ schema.
10. **Remove backward-compat shims** (effort: XS) — `llm/llm_codec.py` and `llm/base.py` are re-export shims. Update all internal imports to canonical paths and delete shims.
