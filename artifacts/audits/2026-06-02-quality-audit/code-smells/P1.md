### Recommendations
1. **Extract `SttMiddleware` error-dispatch helper** (P1, effort: S) — Add a private `_drop_with_error(key, outcome)` method to replace the 6 repeated `_dispatch_error` + `return _DROP` blocks in `middleware_stt.py`.
2. **Extract shared outbound routing helper** (P1, effort: S) — Move the platform/dispatcher/adapter lookup from `StreamingDispatch.dispatch` into a shared `_resolve_outbound_target` helper callable so both `OutboundRouter` and `StreamingDispatch` use the same path.
3. **Extract TTS parameter builder** (P1, effort: XS) — Add `_build_tts_kwargs(msg)` to `TtsDispatch` to unify the repeated `resolve_agent_tts` / `_resolve_agent_fallback_language` / `tts_language_kwargs` resolution in `outbound_tts.py`.
4. **Collapse `SubmitToPoolMiddleware` into sub-methods** (P1, effort: S) — Split `__call__` into `_validate_adapter`, `_check_circuit`, `_register_callbacks`, `_resolve_resume`, and `_build_result`.
5. **Decompose `Hub.__init__` into builder/factory** (P1, effort: M) — Move the 82-line wiring block into a `HubBuilder` or bootstrap factory so `Hub` constructor only accepts a collapsed `deps` dataclass.
6. **Unify resume path boilerplate** (P2, effort: S) — Introduce a `_attempt_resume(path_name, ...)` helper in `path_validation.py` to host the shared pool-idle, session-match, and resume_session logic.
7. **Extract shared extraction runner** (P2, effort: S) — Collapse `_run_concept_extraction` and `_run_preference_extraction` into a single `_run_extraction(prompt, validator, store_fn)` in `session_lifecycle.py`.
8. **Move `_is_transient_error` to adapter layer** (P2, effort: M) — Replace the core-side string matching with a `TransientError` marker exception or an adapter-provided classifier, eliminating the `aiogram`/`discord.py` knowledge in `core/hub`.
