## Design

### Module split (mandatory — SLOC gate)

`src/factory/adapters/omp/` — two source files, each ≤ 300 SLOC:

```
src/factory/adapters/omp/
  __init__.py          — public re-exports only
  omp_worker.py        — NatsAdapterBase subclass, NATS lifecycle, subject routing
  _rpc_bridge.py       — RpcClient construction, digest gate, callback wiring,
                         event translation → NATS publish calls
```

### Class diagram

```
NatsAdapterBase (roxabi_nats)
  └─ OmpWorker (omp_worker.py)
       │  super().__init__(..., heartbeat_subject=_HEARTBEAT_SUBJECT, wait_ready=False)
       │  handle(msg, payload: dict) → dispatch to _rpc_bridge
       └─ RpcBridge (_rpc_bridge.py)
            │  __init__(nats_client, omp_bin: Path, job_id: str)
            │  _verify_digest()     ← CPU-blocking: hash read on __init__, raises DigestMismatchError
            │  _register_callbacks() ← before new_session()
            │  run(prompt: str) → AsyncIterator[BridgeEvent]
            └─ RpcClient (omp_rpc)
```

### Subject constants (`omp_worker.py`)

```python
from roxabi_contracts.jobs.subjects import jobs_progress, jobs_result, jobs_steer, jobs_submit

_CMD_SUBJECT       = jobs_submit("omp")          # subscribe (queue group)
_HEARTBEAT_SUBJECT = "factory.omp.heartbeat"     # publish
_QUEUE_GROUP       = "omp-workers"
```

`jobs_submit("omp")`, `jobs_progress(job_id)`, `jobs_result(job_id)`, `jobs_steer(job_id)`
from `roxabi_contracts.jobs.subjects` must be used for all dynamic subjects — no
hand-crafted f-string subject names.

### Digest gate (`_rpc_bridge.py`)

```python
_PINNED_SHA256 = "b877091c91ebdc8c8d907c4b62681895cd3ae049815858aea7b69ac1d53b7c7b"
_OMP_BIN = Path("/opt/omp/omp")  # image-build constant — NEVER from env
```

On `RpcBridge.__init__`:

1. Read `_OMP_BIN` bytes via `hashlib.sha256`.
2. Compare hex digest against `_PINNED_SHA256`.
3. If mismatch → raise `DigestMismatchError(actual=..., expected=_PINNED_SHA256)`.
4. Worker refuses to start; NATS adapter logs and exits.

`DigestMismatchError` is a local exception in `_rpc_bridge.py`. It must NOT be
swallowed — propagate to `OmpWorker.__init__` which logs and re-raises.

### Callback registration order (`_rpc_bridge.py`)

Per omp_rpc API surface (confirmed in spike #1807):

```python
client.on_message_update(self._on_message_update)
client.on_tool_execution_start(self._on_tool_execution_start)
client.on_agent_end(self._on_agent_end)
await client.new_session()    # ← MUST be last
```

`steer()` is fire-and-forget, between-tool-calls only. It is **never** called from
inside the `prompt_and_wait` await chain. Implementation guard: if `steer()` is
called while `_in_prompt_await` flag is set, raise `SteerViolationError` (local).

### Exception classification (`_rpc_bridge.py`)

Follow the `_classify_exception()` pattern from `clipool_worker.py`. Map exception
types to error codes using `type(exc).__name__` only — never `str(exc)`, `f"{exc}"`,
or `repr(exc)` in bus-bound fields (SanitizedError discipline ADR-073).

```python
def _classify_exception(exc: BaseException) -> WorkerError:
    # Python ≥3.12: asyncio.TimeoutError is alias of TimeoutError;
    # type(exc).__name__ always returns "TimeoutError" — never "asyncio.TimeoutError"
    name = type(exc).__name__
    if name == "DigestMismatchError":
        return WorkerError(code="digest_mismatch", message=name, retryable=False)
    if isinstance(exc, asyncio.TimeoutError):
        return WorkerError(code="timeout", message=name, retryable=True)
    if name in ("ConnectionRefusedError", "BrokenPipeError"):
        return WorkerError(code="connection_error", message=name, retryable=True)
    return WorkerError(code="internal_error", message=name, retryable=False)
```

`WorkerError` is imported from `roxabi_contracts.errors`. The `message` field
must be `type(exc).__name__` — never `str(exc)`, `f"{exc}"`, or `repr(exc)`
(SanitizedError discipline ADR-073).

### Event translation

| omp_rpc callback | NATS subject | Envelope class | Key fields |
|---|---|---|---|
| `on_message_update` | `factory.job.<job_id>.progress` | `JobProgress` | `step="message_update"`, `detail={"partial_text": ...}` |
| `on_tool_execution_start` | `factory.job.<job_id>.progress` | `JobProgress` | `step="tool_start"`, `detail={"tool_name": ..., "tool_id": ..., "tool_input": ...}` |
| `on_agent_end` | `factory.job.<job_id>.result` | `JobResult` | `status="success"`, `data={...}` |
| exception in `prompt_and_wait` | `factory.job.<job_id>.result` | `JobResult` | `status="error"`, `error=_classify_exception(exc)` |

`JobProgress` and `JobResult` are **existing** `WorkEnvelope` subclasses from
`roxabi_contracts.jobs.models` (ADR-084). Do NOT hand-build raw dicts for NATS
publish calls. The per-job subject must be obtained via `jobs_progress(job_id)`
and `jobs_result(job_id)` — no hand-crafted f-strings.

## Data Model

Types used or introduced by this lane:

| Type | Package | Status | Notes |
|---|---|---|---|
| `WorkerError` | `roxabi_contracts.errors` | Existing | `code`, `message` (`type(exc).__name__` only), `retryable` |
| `JobProgress` | `roxabi_contracts.jobs.models` | Existing + additive extension | `WorkEnvelope` subclass; additive optional fields added: `event_type: str \| None = None`, `partial_text: str \| None = None`, `tool_name: str \| None = None`, `tool_id: str \| None = None`, `tool_input: dict[str, Any] \| None = None` |
| `JobResult` | `roxabi_contracts.jobs.models` | Existing (no changes) | `WorkEnvelope` subclass; `status: Literal["success", "error"]`, `data`, `error: WorkerError \| None`; covers omp success/failure without additive fields |

All additive fields on `JobProgress` use `default=None` within `CONTRACT_VERSION`
`"1"` (ADR-084 shim discipline). No new top-level envelope types are introduced —
per-runtime event models are the N×M parallel-path drift trap.

**LlmEvent bypass:** OmpWorker does NOT emit `LlmEvent`. It publishes directly to
`factory.job.<job_id>.progress` and `factory.job.<job_id>.result` via the
omp_rpc callback wiring. `LlmEvent` is the hub's internal turn representation
and is not on the NATS wire from workers.

## `NatsAdapterBase` wiring invariant

`OmpWorker` must pass `wait_ready=False` to `NatsAdapterBase.__init__`
(confirmed at `packages/roxabi-nats/src/roxabi_nats/adapter_base.py:98`).

readiness — OmpWorker is a peer worker, not a hub dependent.

## Security Constraints

| Constraint | Rule |
|---|---|
| OMP_BIN origin | Must be image-build constant `/opt/omp/omp`; never from env |
| Digest gate | Worker refuses start if `sha256(omp_bin) ≠ _PINNED_SHA256` |
| `_verify_digest()` blocking | Hash read in `RpcBridge.__init__` is CPU-blocking (reads full binary synchronously); consider `asyncio.to_thread` in implementation to avoid event-loop stall |
| Exception strings | Never `str(exc)` / `f"{exc}"` / `repr(exc)` in NATS-bound fields; use `type(exc).__name__` |
| omp_rpc exceptions | If `omp_rpc` raises custom exception types, extend `_classify_exception` with additional `isinstance` / `type(exc).__name__` branches; never swallow unknown exceptions silently |
| Bare except | `except Exception:` requires inline justification comment; follow `clipool_worker.py` `_classify_exception` pattern |
| Secret delivery | NATS seed: `type=mount,uid=1500,mode=0400`; LITELLM_API_KEY: `type=env` (ADR exemption required — omp binary reads from env, type=mount impractical; justify inline in PR per axial-review checklist) |
| Container hardening | `NoNewPrivileges=true`, `ReadOnly=true`, `DropCapability=all` |
| UserNS | `keep-id:uid=1500,gid=1500` on standalone container unit (never on both pod and container units) |
