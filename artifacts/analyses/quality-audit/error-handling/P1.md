### Summary
Partition P1 (Hub, lifecycle, ports) has no bare-except or `pass`-swallowed errors, but two silent-swallow `except ValueError: return` sites and one `except Exception` anti-pattern where specific exception types are dispatched via `isinstance` inside the broad catch.

### Findings
| severity | file | line | description |
|----------|------|------|-------------|
| P2 | src/lyra/core/hub/middleware/middleware_stt.py | 134 | `except Exception as exc:` catches `STTNoiseError` and `STTUnavailableError` which are then dispatched via `isinstance` checks inside the block. Specific exception types should be caught before the broad `except Exception`. |
| P2 | src/lyra/core/hub/middleware/middleware_submit.py | 130 | `_notify_session_fallthrough` silently swallows `ValueError` from `Platform(msg.platform)` with `return` and no logging. Invalid platform string in a fresh-session notification path goes unobserved. |
| P2 | src/lyra/core/hub/hub_shutdown.py | 67 | `_notify_one` silently swallows `ValueError` from `Platform(platform_str)` with `return` and no logging during shutdown inflight notification. |
| P3 | src/lyra/core/hub/outbound/outbound_streaming.py | 79 | `except ValueError: raise KeyError(...) from None` suppresses the original `ValueError` chain. The `from None` intentionally hides the parse error, but the caller loses context about why the lookup failed. |
| P3 | src/lyra/core/hub/outbound/outbound_router.py | 134 | `except ValueError: raise KeyError(...) from None` suppresses the original `ValueError` chain. Same pattern as outbound_streaming. |
| P3 | src/lyra/core/lifecycle/circuit_breaker.py | 205 | `except KeyError: raise KeyError(...) from None` suppresses the original `KeyError` chain in `CircuitRegistry.__getitem__`. |

### Recommendations
1. **Reorder STT exception catches** (effort: XS). In `middleware_stt.py`, catch `STTNoiseError`, `STTUnavailableError`, and `asyncio.TimeoutError` before the fallback `except Exception`. This eliminates the `isinstance` dispatch and makes the error contract explicit.
2. **Add logging to silent-swallow sites** (effort: XS). In `middleware_submit.py:130` and `hub_shutdown.py:67`, add a `log.debug` or `log.warning` before the `return` when `Platform()` raises `ValueError`, so invalid platform strings are observable in production.
3. **Review `from None` suppression** (effort: S). For `outbound_streaming.py`, `outbound_router.py`, and `circuit_breaker.py`, consider whether `raise ... from None` is necessary. If the original exception adds no value, keep the suppression; otherwise use `raise ... from exc` to preserve the chain for debugging. Document the decision in a comment.
