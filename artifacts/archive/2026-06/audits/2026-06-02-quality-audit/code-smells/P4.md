### Recommendations
1. **Extract `StreamProcessor.process()` lifecycle shell** (P1, effort: medium) — Split the method into `_setup_emitter()` (EventEmitter + run_id), `_run_stream()` (try/except/finally loop), and `_emit_terminal()` (post-finally error/success routing). The existing `_process_events()` extraction already did half the work; finish the outer shell.
2. **Centralize `close_reasoning_if_open()` in `_dispatch_event()`** (P2, effort: low) — Add a single `yield from self._close_handler.close_reasoning_if_open()` at the top of `_dispatch_event()` for all non-Thinking branches, then remove the 6 identical guard calls from `StreamTextHandler` and `StreamToolHandler` methods.
3. **Resolve aliases once in `Authenticator.resolve()`** (P2, effort: low) — Compute aliases in `resolve()` and pass them into `_resolve_trust()` as a parameter, or refactor `_resolve_trust()` to return `(trust, aliases)` so `resolve()` can reuse the set.
4. **Deduplicate `from_bot_store()` warning logs** (P2, effort: low) — Extract a `_log_missing_config(label, platform, bot_id)` helper that applies the shared format string.
5. **Extract shared `command_args_or_text()` helper** (P3, effort: low) — Shared between `_scraping.py` and `search.py` for the ternary extraction of command args vs. fallback text.
