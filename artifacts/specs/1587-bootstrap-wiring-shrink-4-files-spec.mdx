## Context

Promoted from [frame #1587](/artifacts/frames/1587-bootstrap-wiring-shrink-4-files-frame.mdx).

Four bootstrap files exceed the 300-line quality-gate cap and carry `DEBT:file-exemptions`:

| File | Lines | Exemption | Overage |
|------|-------|-----------|---------|
| `src/lyra/bootstrap/wiring/bootstrap_wiring.py` | 376 | #1494/#1450/#1551/#1556 | +76 |
| `src/lyra/bootstrap/factory/config.py` | 353 | #1467/#1420 | +53 |
| `src/lyra/bootstrap/factory/agent_factory.py` | 351 | #1283/#1492 | +51 |
| `src/lyra/bootstrap/factory/hub_builder.py` | 370 | #1494/#1283/#1492/#1540 | +70 |

All four files share the same pattern: domain-specific helpers (config loading, provider building, hub wiring) were kept inline to avoid proliferating small files. Now the accumulated weight violates the gate and masks structure.

## Goal

Extract domain-specific helpers from the 4 files into dedicated submodules so each caller drops below 300 lines, then remove the 4 `DEBT:file-exemptions` entries.

## Users

- **Primary:** Lyra maintainers editing bootstrap wiring or factory logic
- **Secondary:** Contributors reading bootstrap code to understand startup flow

## Expected Behavior

After extraction, the 4 caller files should read as thin orchestration layers that import helpers from domain modules. No call sites change their signatures or behavior. The new helper modules group functions by domain (e.g., `auth.py`, `pool.py`, `llm.py`, `messages.py` for config loading; `shared_providers.py`, `per_agent_registry.py` for agent factory; `adapter_wiring.py`, `ingest_wiring.py` for bootstrap wiring; `cli_pool.py`, `hub_config.py` for hub builder).
