# Quality Policy — POLICY/DEBT Tag Grammar

Every exception marker in `src/` must be either a policy-approved escape-hatch (`POLICY:<tag>`) or a tracked debt entry (`DEBT:<slug>`). Untagged markers are gate violations.

Related: [`artifacts/debt/INDEX.md`](../artifacts/debt/INDEX.md) | [`docs/playbooks/quality-debt-pipeline.md`](playbooks/quality-debt-pipeline.md)

---

## Tag Grammar

Append the tag after the rule code, separated by ` — ` (em-dash with spaces).

| Surface | POLICY form | DEBT form |
|---|---|---|
| `# noqa: <RULE>` | `# noqa: <RULE> — POLICY:<tag>` | `# noqa: <RULE> — DEBT:<slug>` |
| `# pyright: ignore[<rule>]` | `# pyright: ignore[<rule>] — POLICY:<tag>` | `# pyright: ignore[<rule>] — DEBT:<slug>` |
| `# type: ignore[<rule>]` | `# type: ignore[<rule>] — POLICY:<tag>` | `# type: ignore[<rule>] — DEBT:<slug>` |
| `.importlinter` `ignore_imports` line | N/A — DEBT only | trailing `# DEBT:<slug>` |
| `tools/file_exemptions.txt` entry | N/A — DEBT only | trailing `# DEBT:<slug> — <desc>` |
| `tools/folder_exemptions.txt` entry | N/A — DEBT only | trailing `# DEBT:<slug> — <desc>` |

**Asymmetry rule:** Inline markers (noqa, pyright/type ignore) accept POLICY because intent is contextual and the comment localises it. Config-file waivers (importlinter, exemption files) are bulk bypasses of quality gates — by definition debt; no POLICY at this granularity.

## POLICY Vocabulary

Tags are extensible. Add a new tag when an existing one does not fit the pattern. Quarterly audit prunes unused or misused tags.

| Tag | Common rules | Rationale | Example |
|---|---|---|---|
| `boundary` | BLE001 | `try…except Exception` at CLI entry or top-level async task boundary | `src/lyra/cli/main.py:42` |
| `typer-default` | B008 | `typer.Option(...)` / `typer.Argument(...)` call as default value | `src/lyra/cli/commands.py:17` |
| `decorator-registered` | F401, unused-function | Callable referenced only by `@app.command`, `@hub.handler`, etc. | `src/lyra/commands/ping.py:8` |
| `re-export` | F401 | `__init__.py` stable import surface; symbol re-exported intentionally | `src/lyra/__init__.py:5` |
| `module-level-patch` | F401, E402 | Import-then-patch in tests or fixtures; ordering is load-order-sensitive | `src/lyra/adapters/test_fixtures.py:3` |
| `wiring` | PLR0913 | Bootstrap or factory function with one-to-one dependency parameters | `src/lyra/core/bootstrap.py:88` |
| `migration-sequence` | C901, PLR0915 | Strictly sequential migration steps; branching would break ordering guarantee | `src/lyra/migrations/v3.py:61` |
| `protocol-private` | reportUnusedClass | `Protocol` type used only via duck-typing; never instantiated directly | `src/lyra/core/protocols.py:14` |
| `defensive-narrow` | reportUnnecessaryIsInstance | Runtime narrowing for NATS event payloads where static type is too broad | `src/lyra/core/bus.py:103` |

To extend: add a row to this table in `docs/quality-policy.md` and reference it in the first tagged use. No ADR required; no PR veto on new tags. Quarterly audit reviews additions.

## DEBT Rules

`DEBT:<slug>` tags are **strict**:

1. `<slug>` must match the filename (without `.md`) of a registry file in `artifacts/debt/`.
2. That registry file must have frontmatter `status: open`.
3. A file with `status: drained` is a violation — re-tag or refactor the callsite.
4. A missing registry file is a violation — create it before committing the tag.

The ratchet (`tools/check_quality_debt_ratchet.sh`) enforces all four rules on every pre-push and CI run.

---

## Registry File Conventions

One file per debt entry. Filename = `<slug>.md`, kebab-case. Location: `artifacts/debt/`.

```yaml
---
slug: 'PLR0913-wiring'
status: open
created: 2026-05-11
drain_slice: P2a
rules: [PLR0913]
---
```

Required frontmatter fields: `slug`, `status` (`open` | `drained`), `created`, `rules`.
Optional: `drain_slice` (filled when scheduled for a drain pass).

Required body sections:

- `## Pattern` — what the pattern is and why it is debt rather than a POLICY tag
- `## Sites` — path:line list or "see `artifacts/quality-debt-report.json`"
- `## Drain plan` — how to fix (extract dataclass, replace broad catch, etc.)
- `## Notes` — history, related work, lifecycle events

`artifacts/debt/INDEX.md` is auto-generated by `tools/audit_quality_debt.py`. Do not edit it manually.

## Adding an exception

Follow these steps in order. Stop at the first step that resolves the situation.

**Step 1 — Refactor.** Can the code be changed to eliminate the exception entirely? If yes, do that. No tag needed.

**Step 2 — Justified policy.** Is this an instance of a documented recurring pattern that is correct by design (e.g., a CLI boundary catch, a Typer default, a re-export in `__init__.py`)? If yes, tag `POLICY:<tag>`. If the pattern is new but clearly policy-class, add a row to the POLICY vocab table and tag it.

**Step 3 — Tracked debt.** If neither refactor nor policy applies, this is debt. Create `artifacts/debt/<slug>.md` with the required frontmatter and body stubs, then tag the callsite `DEBT:<slug>`. The slug should describe the rule and pattern, e.g. `PLR0913-wiring` or `BLE001-untracked`.

## Error Message Catalog

| Message | Meaning |
|---|---|
| `untagged exception at <path>:<line> — add POLICY:<tag> or DEBT:<slug>` | Marker has no classification suffix |
| `DEBT:<slug> references missing registry — create artifacts/debt/<slug>.md` | Registry file does not exist |
| `DEBT:<slug> references drained registry — re-tag or refactor` | Registry file has `status: drained`; debt was closed but marker remains |
| `count for (rule, slug) exceeded baseline — refactor or rebaseline (justified only)` | Net debt count grew above committed baseline; refactor to reduce or run `make quality-debt-rebaseline` with written justification |
| `baseline missing generated_by sentinel — regenerate via 'make quality-debt-rebaseline'` | Baseline JSON was edited by hand or is from an older format; only tool-generated baselines are accepted |

## Cutover Migration

The ratchet operates in two modes: **soft** (warn, exit 0) and **hard** (fail, exit 1).

The baseline JSON (`tools/quality_debt_baseline.json`) carries a `cutover_date` field set to merge-date + 7 days on first generation. The ratchet computes its mode at runtime:

- `today < cutover_date` → soft mode: violations print a warning but do not block the push or CI run.
- `today >= cutover_date` → hard mode: violations block the push and fail CI.

No human action is needed to flip the mode. In-flight PRs during the soft window receive warnings only; they are not blocked.

**Emergency override:** set `RATCHET_MODE=soft` to hold soft mode past the cutover date, or `RATCHET_MODE=hard` to enforce hard mode early. CI never sets this variable; it is an operator-only escape hatch.

To regenerate the baseline after a drain pass:

```
make quality-debt-rebaseline
```

The ratchet rejects any baseline where `generated_by != "make quality-debt-rebaseline"`.

## Transient Drain Entries

Registry files in `artifacts/debt/` are **drain targets**, not a permanent backlog. The goal is to delete the pattern from the codebase, not to maintain the registry indefinitely.

When all callsites for a slug are refactored away, flip `status: open → drained` in the registry file. Do **not** delete the file — it is kept for history and re-introduction detection.

A `status: drained` file means: "this pattern existed, was cleaned up, and must not return." The ratchet fails if a `DEBT:<slug>` tag appears in `src/` against a drained registry entry.

---

## DEBT Lifecycle Edge Cases

**Debt drained then re-introduced.** If a drained pattern reappears in `src/`, the ratchet fails with "DEBT:<slug> references drained registry". Options: (a) refactor to remove the re-introduction, (b) re-open the registry entry (flip `status: drained → open`, add a `## Notes` entry explaining the regression), (c) create a new slug if the new instance is a distinct pattern.

**Registry file renamed.** Run `git mv artifacts/debt/<old>.md artifacts/debt/<new>.md` then grep-replace all `DEBT:<old>` tags in `src/` and config files with `DEBT:<new>`. The audit re-scans by path; the old slug will show as missing until all callsites are updated.

**Status transitions.** The allowed lifecycle is `open → drained` (drain pass) and `drained → open` (regression or deliberate re-introduction). The ratchet only fails on `drained` references in `src/`; `open` entries are normal tracked debt.

## Quarterly Audit Cadence

Once per quarter, manually review the POLICY vocab table:

1. **Prune unused tags** — if no callsite in `src/` uses a tag, remove its row from this table.
2. **Demote misused tags** — if a POLICY tag has been applied to sites that are clearly debt (no structural reason to suppress), re-tag those sites as `DEBT:<slug>`, create the registry entry, and remove the POLICY tag.
3. **Consolidate** — if two tags describe the same pattern, merge them with a one-commit grep-replace.

Quarterly audit does not require an ADR or a separate PR; a single commit with a CHANGELOG note in `## Notes` of affected registry files is sufficient.
