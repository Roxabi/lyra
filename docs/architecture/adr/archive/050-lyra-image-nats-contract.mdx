## Original Summary

Froze the wire contract for image generation between lyra hub and imagecli satellite: subjects (`lyra.image.generate.request`), payload schemas, `contract_version: "1"` field, 50 MB cap, heartbeat protocol, and user-controlled-fields sanitization contract.
