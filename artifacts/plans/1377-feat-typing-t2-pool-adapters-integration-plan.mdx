## Summary

Add `typing_publisher` to `Pool`, wrap `process_one()` in `typing_publisher.scope()`, refactor `OutboundEmitter._handle_typing_tail` to call `typing_publisher`, and change all Discord/Telegram adapter typing methods to conditional shims. Land behind `LYRA_TYPING_ENABLED` (default `true` as kill-switch).

## Bootstrap Context

- `typing_publisher` is stored on `Hub` (`Hub._typing_publisher`) and set via `Hub.set_typing_publisher()` in bootstrap.
- `Pool` already has `pairing_manager` as a direct attribute (not via `PoolObserver`).

- `OutboundEmitter` already accepts `typing: ThrottleCapability` and `typing_scope_id` in `__init__`.

#### T2 — Add `typing_publisher.scope()` context manager

- **Description:** Add `@asynccontextmanager` `scope(self, work_scope: WorkScope)` to `TypingPublisher` that calls `publish_started` on entry and `publish_ended` on exit (including exceptions).
- **File:** `src/lyra/transport/typing_publisher.py`
- **Code snippet:**
  ```python
  @asynccontextmanager
  async def scope(self, work_scope: WorkScope):
      await self.publish_started(work_scope)
      try:

      finally:
          await self.publish_ended(work_scope)
  ```

- **Description:** In `_placeholder_lifecycle.py`, change `_handle_typing_tail` to call `emitter.typing_publisher.publish_started/ended` instead of `emitter._start_typing()` / `emitter._cancel_typing()`. When `LYRA_TYPING_ENABLED=false`, the publisher is a no-op; legacy adapter shims handle typing.
- **File:** `src/lyra/outbound/_placeholder_lifecycle.py`
- **Code snippet:**
  ```python
  async def _handle_typing_tail(emitter):
      if emitter._outbound is not None and emitter._outbound.intermediate:
          if emitter.typing_publisher is not None:
              await emitter.typing_publisher.publish_started(emitter._work_scope)
      else:
          if emitter.typing_publisher is not None:
              await emitter.typing_publisher.publish_ended(emitter._work_scope)
  ```
  (Note: `emitter._work_scope` may need to be added or derived from `typing_scope_id`.)
