# Frame — feat(web): smoke adapter

## Problem
Manual M₁ validation (backend flip #1914, agent coexistence) requires Telegram/Discord. No browser-native smoke path exists.

## Users
- Operator / dev running local or staging hub
- CI smoke job validating hub ↔ agent roundtrip

## Scope
- `Platform.WEB` + minimal FastAPI UI (agent picker, chat, SSE)
- NATS subjects `factory.{inbound,outbound}.web.smoke`
- Per-agent bindings via `scope_id=agent:<name>`
- Hub registers web proxy + bindings for all loaded agents

## Out of scope
- Full control-plane dashboard (#1771), `dashboard` wire (#1769), auth/multi-user

## Constraints
- Follow CONTRIBUTING adapter pattern + axial boundary
- Reuse `NatsOutboundListener` / `wire_bot_common`

## Tier
F-lite — single domain (adapters), clear scope.
