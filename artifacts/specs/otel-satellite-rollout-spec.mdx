## Context

Factory workers (clipool, omp) already export spans to `factory-otel` via `NatsAdapterBase` hooks. Voice, image, and LLM satellites live in separate repos and need coordinated PRs **after** `roxabi-contracts`, `roxabi-nats`, and `roxabi-otel` are on `staging`.

## Prerequisite (factory merge gate)

- [ ] `feat/2069-otel-raw-telemetry` merged to `staging`
- [ ] `factory-otel` running on M₁ (`systemctl --user is-active factory-otel`)
- [ ] `curl -sf http://127.0.0.1:8450/healthz`
- [ ] Clipool smoke: one job → line in `~/.local/state/factory/otel/spans.jsonl` with `roxabi.job_id`

## Shared satellite wiring

All NATS-based satellites:

```python
from roxabi_otel.hooks import OtelLifecycleHooks

adapter = MyAdapter(
    ...,
    lifecycle_hooks=OtelLifecycleHooks(service_name="voicecli-stt"),
)
```

Environment (quadlet or `.env`):

```bash
ROXABI_OTEL_ENABLED=1
OTEL_EXPORTER_OTLP_ENDPOINT=http://factory-otel:4317
OTEL_EXPORTER_OTLP_PROTOCOL=grpc
```

**Never** put bytes, prompts, or secrets in `telemetry_attributes()` — see `otel-span-attributes-spec.mdx`.

## Block 6 — voiceCLI

| Task | Done when |
|------|-----------|
| Bump `roxabi-nats`, `roxabi-otel`, `roxabi-contracts` | `uv lock` clean |
| STT adapter: `telemetry_attributes` | `roxabi.blob_ref.in`, `roxabi.model` on span |
| TTS adapter: `telemetry_attributes` | `roxabi.blob_ref.out`, `roxabi.model` |
| Quadlet/env: `OTEL_EXPORTER_OTLP_ENDPOINT=http://factory-otel:4317` | container starts |
| Smoke: STT request | span visible in `GET /api/bff/spans?component=voicecli` |

```python
# STT example (supplemental attrs only)
def telemetry_attributes(self, payload, result):
    return {
        "roxabi.blob_ref.in": payload.get("store_key", ""),
        "roxabi.model": payload.get("model", "unknown"),
    }
```

### llmCLI worker (NATS)

| Task | Done when |
|------|-----------|
| Bump factory packages | lock clean |
| LLM adapter hook | `roxabi.model` (+ token ints if available) |
| Smoke | OMP path span with `roxabi.component=llmcli` |

### llmCLI proxy (HTTP — not NatsAdapterBase)

Configure on M₁/M₂ per runbook — **not** via lifecycle hooks:

```bash
LITELLM_OTEL_V2=true
OTEL_EXPORTER=otlp_grpc
OTEL_ENDPOINT=http://factory-otel:4317
OTEL_SERVICE_NAME=llmcli-proxy
OTEL_INSTRUMENTATION_GENAI_CAPTURE_MESSAGE_CONTENT=no_content
```

**Done when:** LiteLLM request → span with `gen_ai.request.model` in otel-raw.
