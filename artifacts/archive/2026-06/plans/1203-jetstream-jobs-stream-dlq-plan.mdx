### `src/factory/infrastructure/jobs/stream_setup.py`

Mirror of `src/factory/infrastructure/outbound_audio/stream_setup.py` pattern.

```python
"""FACTORY_JOBS JetStream stream provisioning (ADR-079 sole-provisioner, ADR-088)."""

from __future__ import annotations

import logging
from typing import TYPE_CHECKING

import nats.errors
from nats.js.api import RetentionPolicy, StorageType, StreamConfig
from nats.js.errors import BadRequestError

if TYPE_CHECKING:
    from nats.js import JetStreamContext

log = logging.getLogger(__name__)

# ---------------------------------------------------------------------------
# Stream constants (module-level UPPER_SNAKE, no numeric literals inline)
# ---------------------------------------------------------------------------
STREAM_NAME = "FACTORY_JOBS"

# Explicit enumeration — factory.jobs.omp intentionally excluded (core-NATS queue group,
# no bound consumer on this stream; see CLAUDE.md and ADR-088).
SUBJECTS: list[str] = [
    "factory.jobs.vault.>",
    "factory.jobs.web-intel.>",
    "factory.jobs.test.>",
    "factory.jobs.dlq.>",
]

_MAX_AGE_SECONDS = 7 * 24 * 60 * 60   # 7 days — ops DLQ inspection window
_MAX_MSGS = 100_000                    # discard=OLD at limit
_DUPLICATE_WINDOW_SECONDS = 120        # dedup window for Nats-Msg-Id header


# ---------------------------------------------------------------------------
# Config builder
# ---------------------------------------------------------------------------
def _stream_config() -> StreamConfig:
    """Return the canonical FACTORY_JOBS StreamConfig."""
    import nats.js.api as api

    return StreamConfig(
        name=STREAM_NAME,
        subjects=SUBJECTS,
        retention=RetentionPolicy.WORK_QUEUE,
        storage=StorageType.FILE,
        max_age=_MAX_AGE_SECONDS,
        max_msgs=_MAX_MSGS,
        discard=api.DiscardPolicy.OLD,
        num_replicas=1,
        duplicate_window=_DUPLICATE_WINDOW_SECONDS,
    )


# ---------------------------------------------------------------------------
# Public API — called by hub_standalone.py
# ---------------------------------------------------------------------------
async def ensure_jobs_stream(js: "JetStreamContext") -> None:
    """Idempotent: add stream; on BadRequestError (already exists) update config.

    Raises nats.errors.Error on any non-recoverable provisioning failure.
    Called by hub_standalone.py before announce_hub_ready() (ADR-079).
    """
    cfg = _stream_config()
    try:
        await js.add_stream(cfg)
        log.info("FACTORY_JOBS stream created")
    except BadRequestError:
        try:
            await js.update_stream(cfg)
            log.info("FACTORY_JOBS stream config updated")
        except nats.errors.Error:
            log.exception("Failed to update FACTORY_JOBS stream config")
            raise
    except nats.errors.Error:
        log.exception("Failed to create FACTORY_JOBS stream")
        raise
```

**Quality gate checks:**
- No numeric literals inline (all UPPER_SNAKE constants).
- `str_exc_bus_bound`: `log.exception(...)` does NOT publish to NATS — safe.
- SLOC target: ~65 lines — well under 300-line limit.
- `TYPE_CHECKING` guard for `JetStreamContext` (no runtime import cost).

**Note on `DiscardPolicy`:** import path is `nats.js.api.DiscardPolicy` — confirm via

`outbound_audio/stream_setup.py` precedent does not use it (Limits retention defaults to

```mdx
## Decision

Introduce a new `infrastructure/jobs/` subpackage (governance: new subdir requires its
own ADR per `src/factory/infrastructure/CLAUDE.md`) to house:

1. `stream_setup.py` — idempotent `FACTORY_JOBS` WorkQueue JetStream stream provisioning.
2. `dlq_router.py` — advisory-driven DLQ republisher (Slice 3).

Hub is the sole provisioner (ADR-079): `ensure_jobs_stream()` is called in
`hub_standalone.py` before `announce_hub_ready()`. Fail-fast on provisioning error.

## Context

- `factory.jobs.*` dispatch bus (epic #1044) needs durable substrate.
- `factory.jobs.omp` (core-NATS queue group, #1812) is intentionally excluded from stream
  subjects — a WorkQueue copy with no bound consumer accumulates to limits for no benefit.
- `monitor` identity was retired 2026-05-26; DLQ observability is ops-only (hub seed +
  nats CLI) until a real monitoring consumer exists.

## Consequences

- Workers (#1047) bind durable consumers against `FACTORY_JOBS` (lazy, worker-side).
- DLQ lane (`factory.jobs.dlq.>`) is an in-stream retention window; no separate stream.
- Adding a new domain lane = one-line subjects change + hub update path converges live.
```

### `src/factory/infrastructure/jobs/dlq_router.py`

```python
"""DLQ router for FACTORY_JOBS — republishes exhausted jobs to factory.jobs.dlq.<domain>.

Advisory subscription: $JS.EVENT.ADVISORY.CONSUMER.MAX_DELIVERIES.FACTORY_JOBS.>
On advisory: MSG.GET(stream_seq) → republish → MSG.DELETE(stream_seq).

nats-py API:
  jsm = nc.jsm()           # SYNCHRONOUS — nc.jsm() returns JetStreamManager, no await
  raw = await jsm.get_msg(STREAM_NAME, seq=stream_seq)  # api.RawStreamMsg
  await jsm.delete_msg(STREAM_NAME, stream_seq)          # bool
"""

from __future__ import annotations

import json
import logging
from typing import Any, TYPE_CHECKING

if TYPE_CHECKING:
    from nats.js import JetStreamContext

log = logging.getLogger(__name__)

ADVISORY_SUBJECT = (
    "$JS.EVENT.ADVISORY.CONSUMER.MAX_DELIVERIES.FACTORY_JOBS.>"
)
_STREAM_NAME = "FACTORY_JOBS"
_DLQ_PREFIX = "factory.jobs.dlq"

_HDR_ORIG_SUBJECT = "Roxabi-Dlq-Orig-Subject"
_HDR_DELIVERIES = "Roxabi-Dlq-Deliveries"
_HDR_STREAM_SEQ = "Roxabi-Dlq-Stream-Seq"


class DlqRouter:
    """Subscribe to MAX_DELIVERIES advisories and route exhausted jobs to the DLQ lane.

    Lifecycle: start() → (advisory-driven routing) → stop().
    Constructor is synchronous; start() must be awaited before hub is ready.
    """

    def __init__(self, nc: Any, js: "JetStreamContext") -> None:
        self._nc = nc
        self._js = js
        self._sub: Any = None

    async def start(self) -> None:
        """Subscribe to the advisory subject. Called by hub_standalone before announce."""
        self._sub = await self._nc.subscribe(
            ADVISORY_SUBJECT, cb=self._handle
        )
        log.info("DlqRouter: subscribed to %s", ADVISORY_SUBJECT)

    async def stop(self) -> None:
        """Unsubscribe and clean up. Called during hub shutdown."""
        if self._sub is not None:
            await self._sub.unsubscribe()
            self._sub = None
            log.info("DlqRouter: unsubscribed")

    async def _handle(self, msg: Any) -> None:
        """Process one MAX_DELIVERIES advisory — fetch, republish, delete."""
        try:
            advisory = json.loads(msg.data.decode())
        except (ValueError, UnicodeDecodeError):
            log.warning("DlqRouter: failed to decode advisory payload")
            return

        stream_seq = advisory.get("stream_seq")
        if stream_seq is None:
            log.warning(
                "DlqRouter: advisory missing stream_seq — skipping; raw=%r",
                advisory,
            )
            return

        deliveries = advisory.get("deliveries", 0)

        # nc.jsm() is SYNCHRONOUS (confirmed: nats/aio/client.py:2254)
        jsm = self._nc.jsm()

        try:
            raw = await jsm.get_msg(_STREAM_NAME, seq=stream_seq)
        except Exception:  # noqa: BLE001 — nats-py raises nats.errors.* or raw Exception
            # Broad catch: nats-py get_msg raises Exception subclasses that vary by
            # error type; log and skip rather than crashing the advisory loop.
            # Follow-up: tighten to nats.errors.Error when nats-py stabilises.
            log.warning(
                "DlqRouter: MSG.GET failed for seq=%s — skipping DLQ routing",
                stream_seq,
            )
            return

        orig_subject: str = raw.subject or ""
        domain = _extract_domain(orig_subject)
        dlq_subject = f"{_DLQ_PREFIX}.{domain}"

        headers = {
            _HDR_ORIG_SUBJECT: orig_subject,
            _HDR_DELIVERIES: str(deliveries),  # str header value, not the exc
            _HDR_STREAM_SEQ: str(stream_seq),  # str header value, not the exc
        }

        try:
            await self._nc.publish(
                dlq_subject, raw.data or b"", headers=headers
            )
        except Exception:  # noqa: BLE001 — same rationale as get_msg
            log.warning(
                "DlqRouter: republish to %s failed for seq=%s — DLQ copy lost",
                dlq_subject,
                stream_seq,
            )
            return

        try:
            await jsm.delete_msg(_STREAM_NAME, stream_seq)
        except Exception:  # noqa: BLE001 — same rationale
            log.warning(
                "DlqRouter: MSG.DELETE failed for seq=%s — WorkQueue may accumulate",
                stream_seq,
            )


def _extract_domain(subject: str) -> str:
    """Extract domain token from factory.jobs.<domain>.<verb> subject.

    Returns "unknown" if subject does not match the expected pattern.
    Examples:
        "factory.jobs.vault.run" → "vault"
        "factory.jobs.web-intel.fetch" → "web-intel"
        "" → "unknown"
    """
    parts = subject.split(".")
    # Expected: ["factory", "jobs", "<domain>", "<verb>", ...]
    if len(parts) >= 3 and parts[0] == "factory" and parts[1] == "jobs":
        return parts[2]
    return "unknown"
```

**Quality gate checks:**

- `str_exc_bus_bound`: `str(deliveries)` and `str(stream_seq)` are integers, not
  exceptions — safe. No `str(exc)` or `f"{exc}"` in any published field. Headers are
  literal int-to-str conversions.
- `except Exception` blocks: each carries `# noqa: BLE001` and an inline justification
  comment per axial-review requirement. Three occurrences → PR will carry
  `dev-core:axial-adr-review` + `dev-core:security-auditor` labels (auto-applied by CI).
- SLOC target: ~110 lines — under 300-line limit.
- Import layering: no `factory.core` imports — safe.

## Risks

### R1: `nc.jsm()` is synchronous — confirmed

**Finding:** `nats/aio/client.py:2254`:
```python
def jsm(self, **opts) -> nats.js.JetStreamManager:
    """JetStream context for managing JetStream via JS API"""
    return nats.js.JetStreamManager(self, **opts)
```
`jsm()` is a plain `def` — no `await`. Incorrect usage `await nc.jsm()` raises
`TypeError: object JetStreamManager can't be used in 'await' expression`.

**Mitigation:** plan and code explicitly show `jsm = nc.jsm()` (no await), then
`await jsm.get_msg(...)` / `await jsm.delete_msg(...)`.

### R2: `get_msg(seq=0)` falsy guard in nats-py internals

**Finding:** nats-py source uses `if seq:` internally. JetStream sequences start at 1, so
`seq=0` would never appear from a valid advisory. In practice, safe. The plan guards with
`if stream_seq is None` (explicit None check) rather than `if stream_seq` to be safe.

**Mitigation:** the `None`-check guard is explicit in `_handle`. Advisory-sourced `stream_seq`
is always ≥1 if the advisory is well-formed; the `is None` guard rejects missing keys only.

### R3: Advisory JSON field names — nats-py / NATS server contract

**Expected shape** from NATS advisory spec:
```json
{
  "type": "io.nats.jetstream.advisory.v1.max_deliver",
  "stream": "FACTORY_JOBS",
  "consumer": "code-worker",
  "stream_seq": 42,
  "deliveries": 5
}
```
`stream_seq` (not `seq`, not `sequence`) is the field carrying the stream sequence number.
Verify against a real advisory in staging before calling the implementation complete.

**Mitigation:** advisory parse uses `advisory.get("stream_seq")` with explicit `is None`
guard. Log the raw advisory on warning path for diagnostics.

### R4: `DiscardPolicy` import path

`outbound_audio/stream_setup.py` does not use `DiscardPolicy` (Limits retention defaults
to OLD). For WorkQueue streams, explicit `discard=OLD` may or may not be required.

**Mitigation:** verify `nats.js.api.DiscardPolicy` exists via:
```bash

```
If absent, omit the `discard=` kwarg — WorkQueue streams default to discard=OLD.

### R5: `str_exc_bus_bound` gate on `_handle` logging

`log.warning(...)` calls with `stream_seq` and `dlq_subject` do NOT flow to NATS bus —
they are local logging only. The headers dict uses `str(deliveries)` and `str(stream_seq)`
where both are `int`s from JSON decode — NOT from `exc`. Gate should pass cleanly.

**Mitigation:** the gate script (`tools/check_str_exc_bus_bound.sh`) checks for

### R6: WorkQueue + DLQ lane coexistence

**Mitigation:** NATS enforces `max_age=7d` and `max_msgs=100k` with `discard=OLD`. No
action needed. Document clearly in CLAUDE.md for the subpackage.
