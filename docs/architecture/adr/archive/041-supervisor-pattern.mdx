## Status

Superseded by ADR-055 (Quadlet ecosystem conventions) — supervisor pattern fully replaced by Podman Quadlet for Lyra. Original supersession by ADR-047 still applies for the connector-ownership decision.

> **Note (#886/#1036):** This ADR originally described a lyra-owned standalone supervisor
> under a repo-local `deploy/` subtree. That was removed in #886. The subsequent
> `deploy/conf.d/` tenant-conf scaffolding (symlinked from `~/projects/conf.d/` via
> `make register`) was removed in #1036 when supervisord was retired in favour of Podman
> Quadlet (ADR-053). Production is now fully Quadlet — see `deploy/quadlet/*.container`
> and `systemctl --user`.
>
> The original hub-and-spoke body (Decision, Consequences, Implementation) has been
> removed to keep the repo free of stale path references. See git history pre-#886
> for the historical text, or ADR-047 / ADR-053 for the current decisions.
